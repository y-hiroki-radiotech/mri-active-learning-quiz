1. FSPGRの臨床的な本質

一言でいうと： FSPGRは、短いTRで繰り返すGREにRF/gradient spoilingを加えて残留横磁化のコヒーレンスを崩し、縦磁化回復差を主体としたT1コントラストを高速3D収集するシーケンス。
TR × FA
T1コントラスト

短TRほど飽和が増えるため、FAとの組み合わせで考える。

TE
T2*・磁化率

spoiling後も取得中のT2*減衰は残る。通常T1目的ならminimum TEが基本。

BW / Matrix / ARC
SNR・分解能・時間

臨床ではこの3者の交換条件を調整して息止め・高分解能を成立させる。

誤解しやすい点

項目単純化しすぎた理解臨床上より正確な理解
RF spoilingRF位相をランダムにするRF位相を規則的に進めるquadratic phase cyclingが基本。GE系では115.4°前後のphase incrementが報告されている。
T2*spoilingでT2*成分が消える前TR由来の横磁化コヒーレンスを壊す。現在の励起からTEまでの信号にはT2*減衰が残る。
FA大きいほどT1強調大きくするとT1差が増える範囲はあるが、過剰なFAは強い飽和・SNR低下・B1依存を招く。
Ernst角最適T1コントラスト角特定T1/TRで定常状態信号を最大化するFA。最大CNRと一致するとは限らない。
他社との概念対応： GE SPGR/FSPGR ≈ Siemens FLASH系 ≈ Philips T1-FFE系。IR-prepared 3D T1ではGE BRAVO/IR-FSPGR、Siemens MPRAGE、Philips IR-TFE/TFE系という対応で理解すると実践的。

2. 1TRタイムライン：何をspoilingしているのか

RF spoiling

励起RFの位相 φₙ をTRごとに規則的に変化させ、過去の横磁化経路が次のechoに整合して寄与しにくくする。

Gradient spoiling

readout後に十分なgradient momentを与え、残留横磁化を空間的にdephaseさせる。両者を併用することでideal spoiled GREへ近づける。

重要： spoilingは「横磁化を物理的に消滅させる」というより、残留横磁化の位相をばらしてcoherentな信号寄与を抑える操作と考えると理解しやすい。

3. 信号式とErnst角

Ideal spoiled GRE: S ∝ M₀ × [(1 − e^(−TR/T1)) sin α / (1 − e^(−TR/T1) cos α)] × e^(−TE/T2*) Ernst angle: αE = arccos(e^(−TR/T1))

SNR最大化の目安。臨床の最大CNRや造影コントラストの最適FAとは一致しないことがある。

短TRで起こること

TRを短くすると縦磁化が回復する前に次のRFが来るため、同じFAでも飽和が強くなる。

したがって： TRを短縮したらFAも再評価する。TRだけを変更して「同じコントラスト」と考えない。

5. 臨床用途別：どこを触るか

LAVA / LAVA-Flex — 腹部dynamic

文献・GE例
TR 約4–6 msTE minimum / Dixon指定 FA 約10–15°3–5 mm前後

GEのLAVA-Flex臨床例では TR 4.1 ms、TE 1.2 ms、FA 12°、BW 166.67 kHz、288×288、phase FOV 0.9 の例がある。

画質が悪い時

息止め不足： phase matrix↓ → phase FOV↓ → ARC↑ → fractional acquisition。

SNR不足： BW↓ / voxel↑ / ARC↓。NEX増加は息止め延長になるため優先度は低め。

脂肪抑制ムラ： Dixon/LAVA-Flex + 適切なshimを優先。

BRAVO / IR-FSPGR — 頭部3D T1

TR 約8–10 msTE 約3–4 ms / min FA 約8–13°TI 約400–650 ms（実装依存）

IR preparation + segmented FSPGR readout。GM/WMコントラストはTIだけでなく、FA・segmentation・k-space orderingの影響を受ける。

GM/WMコントラスト不足

まず TI → FA → TR の順で考える。IR回復曲線とreadout中の飽和を分けて考える。

3D TOF-MRA

TR 約20–40 msTE shortestFA 約18–25°

目的は単純T1強調ではなく、静止組織を飽和させながらfresh blood inflowを高信号化すること。

末梢血管が消える： FA↓ / slabを薄く / MOTSAを検討。

stentや磁化率： shortest TE、BW↑、FA最適化。

静脈が邪魔： venous SATの位置を確認。

造影3D-MRA / TRICKS

TR minimumTE minimum比較的大きいFA

GdによるT1短縮を最大限利用。TRICKSの臨床例ではTR 4.5 ms、TE 1.97 ms、FA 35°の報告がある。

優先順位

bolus timing / temporal resolution → TR・TE短縮 → acceleration → spatial resolution。

LGE — 心筋遅延造影

IR + spoiled GRETI scout重要

正常心筋のMz≈0となるTIを合わせ、線維化・梗塞を相対的高信号として描出。

最初に触るのはTI

正常心筋が残っている場合、FAやBWより先にnull pointを再評価。造影後時間経過でも最適TIは変化する。

注意： 上記の数値は文献・メーカー臨床例を理解するための代表レンジであり、装置世代、1.5T/3T、coil、parallel imaging、造影条件、施設プロトコルにより変化する。実運用は装置上の承認済みプロトコルを基準に調整する。

6. 困った時のトラブルシュート

1
T1コントラスト不足
TRとFAをセットで評価。短TRでFAが高すぎると両組織が強く飽和し、期待したCNRが出ない場合がある。
2
T2*感・磁化率artifact
TE↓ / BW↑を第一候補。GREなので180° refocusingがなく、SEより磁場不均一に弱い。
3
SNR不足
BW↓ / voxel↑ / acceleration↓。腹部ではNEX↑による息止め延長に注意。
4
息止め時間が長い
phase matrix↓ → phase FOV↓ → ARC/ASSET↑。frequency matrixを先に落とすより、位相方向の削減が効率的。
5
脂肪抑制ムラ
Dixon系（LAVA-Flex等）とshimを検討。特に3TではB0/B1不均一を意識。
6
BRAVOのGM/WM分離不良
TI → FA → TR。readout trainとk-space orderingも含めて考える。
7
TOF末梢血管が消える
FA↓ / slab↓ / MOTSA。血液のslab内滞在時間を短くしてsaturationを減らす。
8
造影MRAの血管信号不足
bolus timing、FA、TE、temporal footprintを確認。単なるFA不足と決めつけない。
9
LGEで正常心筋が明るい
TI scout / null pointを再評価。造影後の時間経過でTIが変わる。

臨床思考の最短ルール

T1 contrast problem → TR × FA Susceptibility / T2* problem → TE ↓, BW ↑ SNR problem → voxel ↑, BW ↓, acceleration ↓ Scan-time problem → phase matrix/FOV ↓, acceleration ↑ IR-prepared problem → TI first Flow problem → FA + slab + flow direction
