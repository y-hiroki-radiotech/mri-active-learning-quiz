要復習（空間周波数とコントラストの混同）
ユーザー解答（原文）

「FSEは1つのTRの間に複数のETLを得る。この複数のETLを使ってk空間を埋めていく。ETLの中心がk空間の中心の低空間周波数領域を埋めて、画像の低コントラスト部分を作る。一方、k空間の周辺はETLの小さいものか大きいものが埋まる。これは高コントラストに影響を及ぼすが、この部分の信号強度が弱いためにT2 blurringの原因になる」

物理的正解と是正のポイント

FSEは1TR内に複数の180°再収束RFを印加し、1つのエコートレイン（ETL個のエコー群）を取得してk空間を充填します。k空間中心（低空間周波数）は画像の組織コントラスト（大まかな濃淡）を担い、実効TE（TEeff）に一致するエコーが配置されます[cite: 1]。一方、周辺部（高空間周波数）は境界・輪郭（空間分解能）を決定します[cite: 1]。ETLを延長するとトレイン後半のエコーがT2緩和（横緩和）により激しく減衰し、k空間の位相方向に低域通過フィルタがかかるため、実空間の点広がり関数（PSF）が拡大してエッジが鈍化（T2 blurring）します[cite: 1]。

今、MRIの中で何が起きている？

90°RFパルスとスライス選択傾斜磁場Gzを同時印加し、スライス内の縦磁化Mzをxy平面に倒して横磁化Mxyを生成しています。

次に起こること

スライスリフェーズ傾斜磁場によりGz印加中に生じた位相の乱れを補正し、Gxプリフェーザーでスピンの位相を進めます。

この数式のお気持ち
傾斜磁場をONにするとはスピンをk空間で走らせること。現在のk空間位置は「通過した傾斜磁場の総面積（時間積分）」で決定されます。
FSEにおける数式のお気持ち・T2 Blurringと実効TEの本質
【数式 1】k空間充填と傾斜磁場面積（グラディエント・モーメント）の物理的対応
k x ( t ) = γ 2 π ∫ 0 t G x ( τ ) d τ , k y ( t ) = γ 2 π ∫ 0 t G y ( τ ) d τ

【数式のお気持ち】k空間の位置は、傾斜磁場のその瞬間の高さではなく「これまでに通過した傾斜磁場の総面積（時間積分値）」で決定されます。プリフェーザー（負の面積）でスピンを一度k空間の左端（−kx,max）へ運び、ADC期間中にReadout傾斜磁場（正の面積）を印加することで左から右へ等速で走らせながらサンプリングを行います。リワインダー（Rewinder）は、直前の位相エンコードで与えた面積を逆極性のパルスで完全に打ち消し（モーメントをゼロに戻し）、次のエコーで新たな位相エンコードを正しく与えるために不可欠な操作です。

【数式 2】エコートレイン中のT2緩和と点広がり関数（PSF）のブロード化
S acquired ( k y ) = S ideal ( k y ) ⋅ exp ( − t ( k y ) T 2 ) ⟶ F − 1 I recon ( y ) = I true ( y ) ∗ PSF ( y )

【数式のお気持ち】k空間の中心（ky≈0）は組織の基礎的な明暗差（コントラスト）を支配し、周辺部（高空間周波数）は物体の鋭利な境界線（エッジ）を描出します[cite: 1]。ETLを長く設定すると、周辺部のデータを取得する時間には横磁化が指数関数的に減衰してしまいます[cite: 1]。これはk空間の周辺部を削ぎ落とす「低域通過フィルタ（ローパスフィルタ）」をかけたことと同義であり、実空間では1点が周囲へ滲み出す点広がり関数（PSF）の幅が拡大します[cite: 1]。これが境界がぼやけるT2 blurringの数学的・物理的正体です[cite: 1]。

物理パラメータ MRI装置が行っている操作 画像・コントラストへの直接的影響
実効TE (TEeff) k空間の中心行（ky=0）を取得するエコー時刻[cite: 1]。この時刻のエコー信号強度が画像全体のコントラストを決定づける[cite: 1]。 前半のエコーを中心におけばPDW寄り、後半のエコーをおけば強いT2強調像となる。
Crusher（クラッシャー） 180°再収束RFの直前と直後に同極性・等面積で印加するGz傾斜磁場。不完全な180°パルスによって生じる不要なFID成分を位相分散（スポイル）させる。 FIDアーチファクトの混入を防止し、純粋なスピンエコー成分のみをADCで取得可能にする。
Rewinder（リワインダー） ADC終了直後に、位相エンコード（Gy）と同面積・逆極性の傾斜磁場を印加して位相分散をゼロに戻す。 エコートレイン内でスピンの位相累積をリセットし、次の180°パルスによる反転を整序する。
