N/2（エヌハーフ）ゴーストを
「なぜ半分ずれるのか」から理解する

奇数・偶数エコーの位相ずれが、なぜ位相エンコード方向のFOV/2シフトとして現れるのか。k空間→位相誤差→画像再構成の順に、動く図で理解します。

まず結論

1. N/2ゴーストとは？

EPI（Echo Planar Imaging）で、元の像をコピーしたような偽像が、位相エンコード方向にFOVの1/2ずれて現れる代表的なアーチファクトです。DWIで特に目にする機会が多い現象です。

覚える像：
「同じ形の影が、PE方向にちょうど半分ずれる」

一般的な呼吸・拍動によるゴーストとは違い、N/2ゴーストは主としてEPIの読み取り極性反転と、それに伴う奇数・偶数エコー間の位相差に由来します。

名称の「N/2」を「収集データの半分が壊れるから」と覚えるより、1行おきの交互誤差が画像空間でFOV/2のシフトを作ると理解する方が本質的です。

2. なぜ「N/2」＝FOVの半分に出るのか？

k空間の位相エンコード行を n = 0,1,2,3... とすると、奇数行と偶数行の間に一定の位相差がある状態は、行ごとに交互に符号や位相が変化する「周期2」の誤差になります。

1, −1, 1, −1, 1, −1, … = exp(iπn)

フーリエ変換では、k空間にこのような交互変調 exp(iπn) を掛けることは、画像空間ではFOV/2だけ平行移動した成分を作ることに対応します。

3. 発生のしくみ：EPIのジグザグ収集から追う

① EPIで高速収集読み取り傾斜磁場を＋/−に高速反転し、1回の励起で多数のk空間ラインを取得。
② 極性が交互奇数エコーは左→右、偶数エコーは右→左のように、読み取り方向が交互。
③ 位相差が生じる勾配遅延、渦電流、B0不均一などで奇数・偶数エコーの位相が完全に一致しない。
④ FOV/2ゴースト1行おきの位相誤差が、再構成後にPE方向へ半FOVシフトしたコピー像を生む。

アニメーション①：EPIのk空間収集

黄色い点は「いま読み取っている場所」のイメージです。実際にはk空間を直線的に往復しながら、位相エンコード方向へ少しずつ移動します。

アニメーション②：奇数・偶数エコーの位相ずれ

重要なのは「逆向きに読んだエコーを並べ直しても、位相が完全には一致しない」ことです。

4. 数式で見ると、なぜFOV/2になる？

簡略化して、奇数/偶数行に ±φ/2 の位相誤差があるとします。各kᵧラインの信号は、概念的に次のように表せます。

S'(n) = S(n) · exp{i·(-1)^n φ/2}

この交互位相は、次の2成分に分解できます。

exp{i·(-1)^n φ/2} = cos(φ/2) + i·(-1)^n sin(φ/2) したがって S'(n) = cos(φ/2)·S(n) + i·sin(φ/2)·[(-1)^n S(n)]

ここで (−1)n = exp(iπn) は、画像空間ではFOV/2シフトに対応します。つまり、再構成像は概念的に：

I'(y) = cos(φ/2)·I(y) + i·sin(φ/2)·I(y + FOV/2)
ここが本質： 位相差 φ がゼロならゴースト成分は消えます。φ が大きくなるほど sin(φ/2) に応じてFOV/2のゴーストが強くなります。

5. 主な原因

🌀
渦電流急峻な傾斜磁場切替により生じ、勾配波形や位相に誤差を与える。
📐
傾斜磁場の遅延・不完全性正負の極性で時間応答が完全に対称でないと、奇数/偶数エコーがずれる。
🧲
B0不均一オフレゾナンスによりEPIの長い読み取り中に位相が蓄積し、奇数/偶数差を増悪させる。
⏱️
読み取りタイミング誤差ADCサンプリングと勾配中心のわずかな不一致が位相ランプを生む。
区別： 呼吸・拍動などの周期運動でもゴーストは出ますが、典型的なN/2ゴーストの中心原因はEPIの奇数・偶数エコー不整合です。

6. TEとの関係：『TEは関係ない』は少し注意

「N/2ゴーストはTEの長短そのものが直接原因ではない」という理解は概ね正しいです。ただし、TEを変えることがEPI readout、echo spacing、オフレゾナンスの位相蓄積などを間接的に変える場合は、ゴーストの程度が変化する可能性があります。

安全な覚え方：
「主因は奇数/偶数エコー間の位相不整合。TEそのものを原因とみなさない。ただしシーケンス全体の条件変更による間接影響はあり得る」

7. 対策・臨床での考え方

Nyquist ghost / phase correction
reference scanやnavigatorで奇数・偶数エコーの位相差を推定して補正。
傾斜磁場キャリブレーション
gradient delay、pre-emphasis、eddy current補正など装置側調整。
シミングの最適化
B0不均一を減らし、EPI中のオフレゾナンス位相蓄積を抑える。
受信・システム点検
継続して強い場合は、装置QC・サービスキャリブレーションの対象。
parallel imaging等でecho trainを短縮
主対策ではないが、EPIの読み取り時間短縮でB0影響や歪みを軽減できることがある。
撮像条件を比較して切り分ける
PE方向変更、shim、reference correctionの有無などで原因を推定。

8. 初学者向け「1分まとめ」

① EPIはk空間を右→左、左→右と交互に高速収集する。
② 装置のわずかな遅延や渦電流などで、奇数・偶数エコーの位相がずれる。
③ その誤差はk空間で「1行おき」に現れる。
④ 1行おきの交互誤差は、フーリエ変換するとFOV/2シフトした成分になる。
⑤ だから、位相エンコード方向に「半分ずれた幽霊像」が出る。
