MRIのバンド幅・SNR・歪みの関係

目的： ラーモアの式と傾斜磁場から出発して、バンド幅、pixel bandwidth、readout時間、k空間、chemical shift、off-resonance歪み、SNR までを、途中の変換式を埋めながらマインドマップ風に整理したHTMLです。

f = γ̄B → B(x)=B₀+Gx → f(x)=f₀+γ̄Gx → BW=γ̄GFOV → σ²∝BW → SNR∝1/√BW
一番大切なのは、「位置を周波数に変換する仕組み」 と 「熱雑音が受信帯域に応じて増える性質」 を1本の流れとしてつなぐことです。

全体マインドマップ

中央の「ラーモアの式」から、各枝へ導出が広がっていきます。

枝ごとの導出

① 位置 → 周波数

傾斜磁場をかけると、位置が周波数に変換される

B(x)=B₀+Gx f(x)=γ̄B(x)=γ̄(B₀+Gx)=γ̄B₀+γ̄Gx f₀=γ̄B₀ とおけば、f(x)=f₀+γ̄Gx
位置 x が変わる
→
磁場 B(x) が変わる
→
周波数 f(x) が変わる
df/dx = γ̄G

これは、1 m あたり何 Hz 周波数が変化するかを表します。Gが大きいほど、同じ位置差でも周波数差が大きくなります。

② 総バンド幅

FOV全体を読むために必要な周波数範囲

x = -FOV/2 のとき fleft = f₀ - γ̄G(FOV/2) x = +FOV/2 のとき fright = f₀ + γ̄G(FOV/2) BWtotal = fright - fleft = [f₀ + γ̄G(FOV/2)] - [f₀ - γ̄G(FOV/2)] = γ̄GFOV

したがって、FOVが広いほど、またgradientが強いほど、必要な受信バンド幅は広がります。

③ pixel bandwidth

1 pixel 幅に割り当てられる周波数範囲

位置差 Δx に対する周波数差 Δf=(df/dx)Δx=γ̄GΔx BWpixel = γ̄GΔx Δx = FOV/Nx BWpixel = γ̄G(FOV/Nx) = (γ̄GFOV)/Nx = BWtotal/Nx

つまり、pixel bandwidth は 1 pixel あたり何 Hz かを表し、chemical shift や歪みの見かけの大きさを決める中心的な量です。

④ k空間・readout時間

gradient は k空間を移動する速さも決める

kₓ(t)=γ̄∫Gₓ(t)dt 定常 readout gradient なら dkₓ/dt = γ̄G Δk = 1/FOV, kmax = 1/(2Δx) 2kmax = γ̄G · Tread Tread = 2kmax/(γ̄G) = [2×1/(2Δx)]/(γ̄G)=1/(γ̄GΔx) BWpixel = γ̄GΔx より Tread = 1/BWpixel BWtotal = Nx·BWpixel より Tread = Nx/BWtotal

高BWほど短時間でreadoutでき、低BWほどゆっくりreadoutします。

⑤ ノイズとSNR

熱雑音は帯域が広いほど増える

noise power ∝ BWtotal したがって σ² ∝ BWtotal よって σ ∝ √BWtotal SNR = S/σ 同一条件で S を一定とみなせば SNR ∝ 1/√BWtotal
BW↑
→
ノイズ σ↑
→
SNR↓

これがMRIでよく使う有名な関係式です。

⑥ chemical shift と off-resonance歪み

周波数ずれは位置ずれに変換される

df/dx = γ̄G 周波数ずれ Δf に対する位置ずれ Δxshift = Δf/(γ̄G) pixel単位のずれ shift[pixel] = Δxshift/Δx = [Δf/(γ̄G)]/Δx = Δf/(γ̄GΔx) = Δf/BWpixel

chemical shift でも off-resonance でも数式の構造は同じです。したがって、BWpixel が小さいほどずれが大きいとわかります。

SNRの拡張式との接続

BWの議論を、普段使うMRIのSNR式に接続すると次のように整理できます。

SNR ∝ Vvoxel · √NEX / √BW Vvoxel = ΔxΔyΔz したがって SNR ∝ (ΔxΔyΔz)√NEX / √BW
voxelを大きくする
→
SNR↑
NEXを上げる
→
SNR↑（√NEX）
BWを下げる
→
SNR↑（1/√BW）
ただし、BWを下げてSNRを稼ぐと、chemical shift や off-resonance歪みは増えます。したがって臨床では、SNR・歪み・分解能・撮像時間のトレードオフとして考えます。

超要約

1本の主幹だけを見る f = γ̄B B(x)=B₀+Gx f(x)=γ̄(B₀+Gx)=f₀+γ̄Gx BWtotal = γ̄GFOV σ²∝BW → σ∝√BW SNR = S/σ ∝ 1/√BW
歪みの主幹だけを見る df/dx = γ̄G Δxshift = Δf/(γ̄G) shift[pixel] = Δf/BWpixel

したがって、BWpixel が小さいほど、chemical shift や off-resonance によるずれは大きく見えるとわかります。

readout時間の主幹だけを見る kₓ(t)=γ̄∫Gₓ(t)dt dkₓ/dt = γ̄G Tread = 1/BWpixel = Nx/BWtotal

高BWでは短時間readout、低BWでは長時間readoutになります。
