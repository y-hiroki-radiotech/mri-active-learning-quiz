Bloch方程式から反転回復（IR）法の式を完全導出

縦緩和の微分方程式を「なぜこの形なのか」から始め、変数分離、積分、指数関数への変形、初期条件の適用まで一段ずつ追い、最終的に Mz(t)=M0(1−2e−t/T1) が現れる理由を理解します。

1. 出発点：Bloch方程式の縦成分

静磁場 B0 を z 方向に取ると、RFパルス後の縦磁化 Mz は熱平衡値 M0 に戻ろうとします。その回復を表すBloch方程式の縦成分は、

dMz/dt = −(Mz−M0)/T1

です。同じ式を符号の意味が見えやすいように書けば、

dMz/dt = (M0−Mz)/T1
各量の意味
Mz(t)：時刻 t の縦磁化 ／ M0：熱平衡時の縦磁化 ／ T1：縦緩和時間。
右辺の M0−Mz は「現在地からゴール M0 まで、あとどれだけ離れているか」を表します。差が大きいほど回復速度は大きく、Mz が M0 に近づくほど速度は0へ近づきます。

例えば IR 直後は Mz=−M0 なので、初期回復速度は

dMz/dt |t=0 = {M0−(−M0)}/T1 = 2M0/T1

となります。ここですでに「−M0 から +M0 までの差が 2M0」であることが見えています。

2. 微分方程式を変数分離法で解く

Step 1 Mz と t を左右に分ける

出発式

dMz/dt = −(Mz−M0)/T1

の両辺に dt を掛けると、

dMz = −(Mz−M0)/T1 · dt

さらに両辺を Mz−M0 で割ります。

dMz/(Mz−M0) = −dt/T1

これで左辺は Mz だけ、右辺は t だけになりました。これが「変数分離」です。

Step 2 両辺を積分する

∫ dMz/(Mz−M0) = ∫ −dt/T1

左辺では u=Mz−M0 と置けば du=dMz なので、基本公式 ∫du/u=ln|u| を使えます。

ln|Mz−M0| = −t/T1 + C1
なぜ絶対値が付くのか： ln x は x>0 で定義されますが、IR直後は Mz−M0=−2M0<0 です。そこで積分結果は ln|Mz−M0| と書く必要があります。

Step 3 対数を外す

両辺を e の指数にします。

eln|Mz−M0| = e−t/T1+C₁
|Mz−M0| = eC₁e−t/T1

絶対値を外すと ± が生じますが、±eC₁ は時刻によらない一つの定数なので、まとめて C と置けます。

Mz−M0 = C e−t/T1

したがって一般解は、

Mz(t)=M0+C e−t/T1

です。指数項は時間とともに0へ減衰するので、t→∞ では必ず Mz→M0 となります。つまり、この一般解そのものが「平衡値との差が指数関数的に消える」ことを表しています。

3. 初期条件を一般化すると本質が見える

t=0 の縦磁化を Mz(0) とします。一般解へ t=0 を代入すると、e0=1 なので、

Mz(0)=M0+C
∴ C=Mz(0)−M0

よって縦緩和の最も一般的な形は、

Mz(t)=M0+[Mz(0)−M0]e−t/T1
C は「初期値 − 平衡値」です。言い換えると、平衡値から見た初期偏差を表します。その偏差だけが e−t/T1 に従って消えていきます。

4. 180°反転パルスを入れると「2」が出る

理想的な180°RFパルスでは、パルス直前の +M0 が z 軸の反対側へ完全に反転します。

Mz(0)=−M0

したがって積分定数は、

C=Mz(0)−M0=−M0−M0=−2M0

これを一般解へ代入すると、

Mz(t)=M0−2M0e−t/T1

M0 でくくれば、

Mz(t)=M0(1−2e−t/T1)

IRでは −M₀ から出発し、0を通過して +M₀ に漸近する。

5. なぜ飽和回復は「1」、IRは「2」なのか

項目飽和回復（理想的に Mz=0）反転回復（180°）
t=0 の初期値0−M₀
t→∞ のゴール+M₀+M₀
初期値−平衡値−M₀−2M₀
C−M₀−2M₀
回復式M₀(1−e−t/T1)M₀(1−2e−t/T1)

つまり「2」はBloch方程式そのものに特別に埋め込まれている数字ではありません。180°パルスによって初期値が −M₀ になったという初期条件から生じます。−M₀ から +M₀ までの全幅が 2M₀ であるため、初期偏差 C が −2M₀ になるのです。

6. T1の意味を式から読む

T1 は「平衡値との差」が 1/e ≈ 0.368 倍になる時間です。IRでは初期偏差が −2M₀ なので、t=T1 では、

Mz(T1)=M0(1−2/e) ≈ 0.264M0

また Mz=0 となる時刻（null point）は、

0=1−2e−t/T1 → e−t/T1=1/2 → t=T1 ln2 ≈0.693T1

IR法で特定組織の信号を抑制する考え方（STIRやFLAIR）は、この「縦磁化が0を横切る時刻」を利用することにつながります。

7. 最終チェック：式が物理的に正しいか

t=0： Mz=M0(1−2)=−M0 → 180°直後の条件と一致。
t→∞： e−t/T1→0 なので Mz→M0 → 熱平衡へ回復。
途中： Mz<M0 の間は dMz/dt>0 → 縦磁化は常に +M0 方向へ回復。

まとめ

Bloch方程式の縦緩和は「平衡値との差が大きいほど速く戻る」という一次の緩和過程です。変数分離と積分によって一般解 Mz(t)=M0+[Mz(0)−M0]e−t/T1 が得られ、IRでは Mz(0)=−M0 を代入するだけで係数 −2M0 が決まります。したがって「2」の正体は、180°反転によって生じた −M₀から+M₀までの2M₀の初期偏差です。

※ 理想的な瞬時180°パルス、完全な反転、RF直前に熱平衡 M₀ にあることを仮定した基本式です。実際の撮像では反転効率、TR、読み出しパルスなどの影響を考慮する場合があります。
