Phase FOV・Freq. Dir・No Phase Wrapを「外す」理由

「スライス位置をコピーしたいだけなのに、なぜこの3項目はコピーしないのか？」を、位相エンコード・k空間・折り返し・アーチファクト方向から理解するための実践教材。

結論：コピーしたいのは「幾何学」であって、「位相エンコード戦略」ではない

Phase FOV・Freq. Dir・No Phase Wrapを外す主目的は、コピー先シリーズが本来持っている位相エンコード方向・撮像範囲・折り返し対策を上書きしないためです。

Copy Rxでは、前シリーズのスライス位置・角度・厚さ・間隔などを再利用できます。しかし、Freq. Dir.は読み出し方向を決めるだけでなく、直交する位相方向も決めます。 Phase FOVはその位相方向の撮像範囲を決め、No Phase Wrapはその同じ位相方向へのオーバーサンプリングを行います。

つまり、この3項目は別々のつまみではなく、実質的に「位相エンコード設計の1セット」です。スライス位置だけを揃えたい場合、ここまでコピーすると「別コントラストを同じ位置で撮る」という目的を超えて、コピー元のアーチファクト対策まで持ち込んでしまいます。

1. まず3項目の役割を整理

方向を決める

Freq. Dir.

GEでは表示されるのは主に周波数エンコード（readout）方向です。

  • Freq. Dir.を変更すると、面内でfrequency と phase が入れ替わる
  • したがって、位相ゴースト・wrap・EPI歪み等の方向も変わる
  • 化学シフトは主にfrequency方向へ現れるため、その方向も変わる
位相方向の広さを決める

Phase FOV

Frequency側FOVに対する、phase方向FOVの比率です。

FOV_phase = FOV_freq × Phase FOV

例：FOV 24 cm、Phase FOV 0.75 → 位相方向は18 cm。

位相方向のwrap対策

No Phase Wrap

位相方向の折り返しを防ぐためのphase oversamplingです。

  • 位相方向の取得範囲を広げる
  • 最終表示は目的FOVに戻す
  • 実装によりNEX・scan time・互換性へ影響

2. Freq. Dir.をコピーすると、実は「Phase Dir.までコピー」している

GEのFreq. Dir.は「単なる表示向き」ではありません。面内のreadout/phaseの割当を変えるため、アーチファクト設計そのものが変わります。

k空間では何が変わる？

Cartesian MRIでは、readout中に連続的に kx を走査し、TRごとに位相エンコード量を変えて ky のラインを選びます。

k(t) = (γ / 2π) ∫ G(τ) dτ

Freq. Dir.をswapするということは、患者座標上の「どちらの軸をreadoutとして連続サンプリングし、どちらをphase encodeとしてラインごとに進めるか」を入れ替えることです。

コピー元で最適だったFreq. Dir.が、コピー先でも最適とは限りません。
pulse sequence、flow、motion、EPI、chemical shift、parallel imagingなどの条件が変われば、望ましい方向も変わり得ます。

3. Phase FOVをコピーすると「位相方向の撮像範囲」まで上書きする

Phase FOVを小さくするとphase encode数を減らして撮像時間を短縮できますが、位相方向に解剖がはみ出すとaliasing（wrap around）が発生します。

GEの旧来のオペレータ資料では、Phase FOVを下げるとphase encoding stepsが減ってscan timeが短くなる一方、SNRがわずかに下がり、位相方向の範囲が狭くなることが説明されています。

したがってCopy RxでPhase FOVまでコピーすると、コピー先が本来1.0で設計されていたのに0.75へ変わる、あるいはその逆が起こり得ます。

コピーされた状態起こり得ること
Phase FOVが小さすぎる位相方向の解剖がFOV外に出てwrap。目的部位に重なる可能性。
Phase FOVが大きすぎる不要にphase encodeが増え、scan timeが延びることがある。
Freq. Dir.まで同時コピー「Phase FOVを短くした方向」そのものが90°変わるため、意図していない方向のcoverageが不足。

4. No Phase Wrapをコピーすると「折り返し対策」までコピーする

No Phase Wrap（NPW）は、位相方向の外側にある解剖が折り返してくるのを防ぐ機能です。GEの従来資料では、位相方向のFOVとphase encoding stepsを拡張し、目的FOVを保ったままaliasingを避ける仕組みとして説明されています。

NPW OFF

Phase FOV外の信号も受信

↓

Nyquist条件を満たさない位相方向で位置が一意に決まらない

↓

反対側へwrap

→
NPW ON

phase方向をoversample

↓

外側の信号も広いFOV内で正しく位置付け

↓

中央の目的FOVを再構成

ただし「NPWは常にONが安全」ではありません。
GEの実装では、sequence/software releaseによりNEX、overscan、scan time、motion artifact、Square Pixel、parallel imagingなどとの互換性に制約があります。古いGE資料ではPhase FOV<1との非互換も明記されています。現在のArtist/Heroでは必ず装置上の警告・自施設プロトコル・該当ソフトウェア版マニュアルを優先してください。

5. 3項目は「連鎖」している

6. 外さなかったら、具体的にどうなる？

項目外さずコピーした場合臨床上の見え方・問題
Freq. Dir. コピー元のreadout方向がコピー先にも適用され、phase方向も同時に入れ替わる。 呼吸・嚥下・血流などのghost方向が変わり、ROIへ重なる。chemical shiftの方向、EPIの歪み方向も変化し得る。
Phase FOV コピー元の位相方向coverageがそのまま入る。 小さすぎればwrap、大きすぎれば時間効率を失う。Freq. Dir.もコピーされると「短くなる方向」も変わる。
No Phase Wrap コピー元のphase oversampling戦略まで引き継ぐ。 不要なoversampling、scan time/NEXの変化、motion感度や互換性の変化。逆にOFFをコピーすればwrap防止が失われる場合もある。
3項目すべて コピー元の「位相方向＋そのFOV＋anti-wrap」を丸ごと移植。 スライス位置は正しいのに、画像アーチファクトだけが想定外になる“静かな設定ミス”が起こり得る。
重要：外さなければ必ず失敗する、という意味ではありません。
同一plane・同一sequence・同じartifact strategyで完全に再現したいなら、コピーする方が合理的な場合もあります。問題は「位置だけコピーしたつもり」が成立しなくなることです。

8. 実務でのチェック手順

  1. Copy Rxの目的を先に決める：「geometryのみ」か「撮像条件も含む完全再現」か。
  2. geometryのみなら、Phase FOV・Freq. Dir.・No Phase Wrapは原則コピー対象から外す。
  3. コピー後、Freq. Dir.を見てphase方向を頭の中で明示する。
  4. そのphase方向に解剖がPhase FOV内へ収まるか確認。
  5. 収まらないなら、Phase FOVを広げる／No Phase Wrapを使う／Freq. Dir.を変える／SATを使う、をシーケンスに応じて選択。
  6. 最後にscan time、NEX、parallel imaging、EPI、Square Pixel等との互換性を確認。
覚え方：
「Copy Rxでコピーするのは断面。Phase FOV・Freq Dir・NPWは“そのシーケンスの位相設計”なので、いったんコピーから外し、コピー先で再判断する。」

9. 原理を1枚でまとめる

設定物理的に決めるものコピー先で再判断する理由
Freq. Dir.readout gradientの方向。直交軸がphase encode方向。motion/flow ghost、chemical shift、EPI distortion等の最適方向がsequenceごとに異なる。
Phase FOV位相方向の空間coverageとphase encode量。解剖の広がりとscan timeのバランスがseriesごとに異なる。
No Phase Wrap位相方向oversamplingによるaliasing防止。必要性・NEX/scan time・互換性がsequence/softwareに依存。

3つの共通点は「位相方向をどう設計するか」。したがってslice geometryのコピーとは切り離して扱うのが最も理解しやすい運用です。
