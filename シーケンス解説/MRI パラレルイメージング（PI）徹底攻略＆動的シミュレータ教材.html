パラレルイメージング（Parallel Imaging）徹底攻略

多チャンネル受信コイルの局所空間感度差を利用したk空間間引き・シーケンス時間短縮・SNRトレードオフの物理的統合理解

パラレルイメージング（PI）とは何か？

パラレルイメージング（PI）とは、複数の小型受信コイルエレメントを並列配置した位相アレイコイル（Phased Array Coil）を用い、各コイルがもつ固有の「空間感度差（感度プロファイル）」を空間位置の識別に利用することで、k空間の位相エンコード行を間引いて撮像時間を短縮する技術です。

  • 「パラレル」の由来：複数のコイルエレメントが被写体からのMR信号を同時かつ並列（Parallel）に受信することから命名されました。
  • 基本動作：位相エンコードステップを1行おき（加速因子 R=2）や2行おき（R=3）にスキップして収集します。
  • エイリアシングの必然性：サンプリング間隔 Δky が広がるため、ナイキスト基準を満たさなくなり、そのままフーリエ変換すると位相エンコード方向に画像が重なり合う「折り返し（エイリアシング）」が発生します。
  • 復元の鍵：各コイルに近い部位は信号が強く、遠い部位は弱いという空間感度差を行列計算（SENSE）または周波数補間（GRAPPA）で解き、重なり合ったピクセルを分離します。
本質的な臨床メリット
傾斜磁場アンプの物理限界（最大磁場強度やスルーレートによる末梢神経刺激制限）に抵触することなく、「純粋に収集するTR回数またはEPIエコートレイン長を1/Rに減らす」ことで撮像時間を半減〜1/4に短縮できます。

臨床を二分する2大方式：SENSE と GRAPPA

パラレルイメージングは、「どこで折り返しを展開するか」によって大きく2系統に分かれます。実空間（画像領域）で連立方程式を解くSENSEと、周波数空間（k空間領域）で抜けたラインを補間するGRAPPAです。

SENSEの数学的メカニズム（コイル2個・R=2の場合）

加速因子 R=2 のとき、折り返されたピクセル信号 A1,A2 は、真の組織信号 O1,O2 が各コイル感度 Sij で重み付けされて合算された値です。

[ A1 A2 ] = [ S11 S12 S21 S22 ] [ O1 O2 ] ⇒ [ O1 O2 ] = [ S11 S12 S21 S22 ] -1 [ A1 A2 ]
数式のお気持ち

「未知数2つ（真のピクセル2箇所）に対して、空間的に異なる場所から見た2つの目（コイル感度）があるから、連立方程式を逆算して元の一対一の像を取り戻せる」という原理です。

物理・数学的原理：PIにおけるSNR低下の法則

パラレルイメージングを適用すると、撮像時間が短縮される代償として必ず信号雑音比（SNR）が低下します。この関係は以下の厳密な数式で定義されます。

SNRPI = SNR0 g × R
  • 各記号の意味と物理量：
    • SNRPI：パラレルイメージング適用後の画像SNR
    • SNR0：間引きを行わない通常収集時の画像SNR
    • R：加速因子（Reduction / Acceleration factor, R≥1）
    • g：幾何学的配置因子（Geometry factor / g-factor, 局所空間変数, g≥1）
  • 2つのSNR低下要因の分離：
    • サンプリング数減少損（1/R）：収集データ点数が 1/R に減ることで生じる統計ノイズ増大。R=2 で基準の約 71% に低下します。
    • コイル直交性損（g 因子）：コイル感度差が小さく連立方程式が解きにくい領域（深部・中心部）でノイズが増幅される現象です（g>1）。
加速因子R設定の臨床ルール
加速因子 R を過大に設定すると、感度行列の条件数が悪化して g 因子が跳ね上がり、画像中央部に激しい砂嵐状ノイズ（ノイズバンド）が発生します。日常臨床では R=2（多くても3程度） が実用限界です。

臨床シーン・シーケンス PIを使用する技術的理由・臨床的メリット
腹部造影ダイナミックMRI
(肝細胞癌・膵臓など)		 動脈相の灌流ピークは十数秒です。PI（R=2〜3）により息止め時間を20秒以下に短縮し、呼吸停止限界内で血流ピークを捉え体動アーチファクトを排除します。
頭部・体幹部 拡散強調画像
(DWI: Single-shot EPI)		 EPIは位相エンコード方向の帯域幅が極めて狭く磁化率歪みが多発します。PIによってエコートレイン長（ETL）とエコースペースを短縮し、位相誤差の蓄積を防いで頭蓋底や頸部の歪みを劇的に抑えます。
3D 造影・非造影 MRA
(頸部・下肢・腎動脈)		 3次元収集の膨大な位相・スライスエンコードステップを2軸方向（2D-PI）で圧縮し、高精細な等方性ボクセルを数分の現実的時間で描出可能にします。
心臓シネ・遅延造影（LGE）
(bSSFP / TrueFISP)		 心拍同期下において、1心拍あたりに収集できるビュー数を圧縮。1回の息止めで左室駆出率（EF）や心筋壁運動を高時間分解能で評価できます。
3T超高磁場MRIでの撮像
(全身領域)		 3Tで急増するRF照射エネルギー（SAR制限）に対し、PIでRFパルス数を削減してTR短縮を維持。3Tの高い元SNRがPIのSNR低下を相殺します。
