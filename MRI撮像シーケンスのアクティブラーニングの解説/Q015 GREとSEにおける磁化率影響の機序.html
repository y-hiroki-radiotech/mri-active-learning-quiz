提出された解答 「グラジエントエコー法はスピンエコー法と異なり、180度反転パルスを用いない。それによってスピンスピン格子緩和の影響で、すなわち局所の双極子幹磁場の影響を受けて位相拡散したものが再収束しないため。」
標準正答（模範解答） 「SE法では180°再収束パルスによって、組織境界の磁化率差等による静的な局所静磁場不均一（可逆的位相分散：T2′成分）が反転され完全に再収束（リフェーズ）する。これに対し、GRE法は180°パルスを用いず傾斜磁場の反転のみでエコーを形成するため、局所磁場不均一に起因する位相分散がキャンセルされず累積し、T2*減衰として強い信号低下・磁化率効果が生じるため。」
正しく理解できている点 SE法とGRE法の根本的な差異が「180°パルスの有無」にあり、180°パルスを用いないGRE法では「位相分散が再収束しない」というマクロな結末を正確に捉えられています。
最大の修正点（用語・概念の誤り） 「スピンスピン格子緩和」という混同用語（縦緩和T1と横緩和T2の合成語）を使用している点、および「双極子間相互作用」と「磁化率による静磁場不均一」の混同を直ちに解消する必要があります。
根本的誤概念 可逆的位相分散（T2′）と不可逆的位相分散（純T2）の取り違え。
「双極子間相互作用」は分子の熱運動に伴う微視的で不可逆な現象であり、SE法の180°パルスをもってしても再収束できない成分（純粋なT2）です。一方、磁化率効果は物質境界面で生じる巨視的・静的な局所磁場不均一（ΔBlocal）であり、時間反転によって180°パルスで再収束できる成分（T2′）です。

誤概念の徹底解剖：何が混同されていたのか？

1. 「スピン-格子緩和」と「スピン-スピン緩和」の峻別

解答文にある「スピンスピン格子緩和」は実在しない用語です。MRIの緩和現象は以下の2つに明確に二分されます。

スピン-格子緩和
(縦緩和)		 T1 縦磁化 Mz の回復 スピンから周囲の格子（熱浴）へのエネルギー放出 あり（熱平衡へ向かう）

2. 「双極子間相互作用」vs「磁化率効果（静磁場不均一）」

重要原理：なぜSE法は磁化率を打ち消し、GRE法は強く受けるのか？

1. SE法（スピンエコー法）のリフェーズ機構

SE法では、90°パルス印加から時間 TE / 2 の時点で180°再収束（リフェーズ）パルスを照射します。

  • 位相の反転：磁場が高い場所で早く進みすぎたスピンと、磁場が低く遅れたスピンの空間的位置関係が、180°パルスによって点対称に反転します。
  • 再収束の成立：磁化率による磁場の歪み（ΔBlocal）が時間的に変化しない（静的である）ため、反転後もちょうど同じ時間（TE / 2）が経過した t = TE の瞬間に、先行していたスピンに遅れていたスピンが完全に追いつきます。これにより、磁化率差による位相分散は完璧にゼロ（打ち消し）になります。
2. GRE法（グラジエントエコー法）のリフェーズ限界

GRE法は180°RFパルスを使用しません。代わりに「読み取り傾斜磁場の極性反転（バイポーラ傾斜磁場）」によってエコーを形成します。

  • 傾斜磁場の位相しか戻せない：装置の傾斜磁場コイルによって人工的に印加したディフェーズ勾配の位相ズレは、反対極性のリフェーズ勾配によって相殺できます。
  • 局所磁場不均一は放置される：被写体内部の磁化率差（空気と副鼻腔、ヘモジデリン、金属など）が作り出す局所静磁場勾配（ΔBlocal）は、外部傾斜磁場をいくら反転させても逆転しません。スピンの進み・遅れは単調に開いていき、エコー時刻（TE）になっても広大な位相分散が残存します。

数式解説：緩和速度と位相分散の定量的理解

【重要式 1】 実効横緩和速度 R₂* の加成性
R2* = R2 + R2′  ⇒  1T2* = 1T2 + 1T2′ = 1T2 + γ · ΔBlocal
記号 物理的意味 単位 SE法での挙動 GRE法での挙動
R2* (1 / T2*) 実効横緩和速度（全体の見かけの減衰） s−1 (Hz) 影響を受けない 直接反映される（急激な減衰）
R2 (1 / T2) 純粋な横緩和速度（不可逆的スピン間相互作用） s−1 (Hz) この速度のみで減衰 減衰の一部として寄与
R2′ (1 / T2′) 磁場不均一による可逆的緩和速度 s−1 (Hz) 180°パルスで完全消去（= 0） 消去されずそのまま残存
γ 磁気回転比（水素プロトン: 約 42.58 MHz/T） rad / (s·T) 定数 定数
ΔBlocal 磁化率差による局所静磁場不均一 T (テスラ) 180°パルスでリフェーズ 不均一が大きいほど T₂* が極短化
【重要式 2】 磁化率によるスピン位相角の蓄積
ϕlocal(t) = γ · ΔBlocal · t

比例・変数増減と臨床への影響：

  • エコー時間（TE）への比例： 時間 t が長くなるほど位相差 ϕ は扇状に拡大します。GRE法でTEを長くすると磁化率効果（低信号・信号消失）が激化するのはこのためです。
  • 主磁場強度（B₀）への比例： 局所磁場不均一は ΔBlocal = Δχ · B0 で決まります。そのため、3.0T装置では1.5T装置の2倍の磁化率効果が現れます。
【重要式 3】 エコー信号強度の決定式比較
SSE(TE) ∝ M0 · e−TE / T2  vs  SGRE(TE) ∝ M0 · e−TE / T2*

常に T2* < T2 であるため、同一のTEであってもGRE法はSE法に比べて信号減衰が圧倒的に速く、磁化率差のある部位（出血巣、石灰化、空気境界、金属）が顕著な「低信号（黒抜き・ブルーミング効果）」として描出されます。
