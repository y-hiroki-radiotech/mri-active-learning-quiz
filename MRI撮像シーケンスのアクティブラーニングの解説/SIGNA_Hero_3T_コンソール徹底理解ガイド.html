1. コンソールは「5層」で読む

画面上の数値をバラバラに読むのではなく、下の順番で読むと、パラメータ変更の意味が整理できます。

① Geometryどこを、どの範囲で撮るか
FOV / Phase FOV / Slice / Slab /方向
② Resolution何mmで見るか
Matrix / voxel / ZRes / spacing
③ Signal & Contrast何を明るくするか
TR / TE / FA / ETL / BW / NEX
④ Acceleration & Recon何を間引き、どう再構成するか
ARC / HyperSense / AIR Recon DL
⑤ Calibration & Safety均一性と制約は大丈夫か
PURE / Shim / RF Drive / SAR / B1+rms
実務の基本：「画質が悪い → とりあえずNEXを上げる」のではなく、どの層の問題かを最初に切り分けます。例えば、脂肪抑制むらならNEXではなくShim/B0、wrapならPhase FOV/No Phase Wrap、z方向の甘さならZRes、FSEのぼけならETL/echo spacingが主戦場です。

4. GeometryとVoxel：分解能は「FOV ÷ Matrix」から始まる

4-1. pixel sizeの基本

Pixel size (frequency) = FOVfreq / Matrixfreq
Pixel size (phase) = FOVphase / Matrixphase

添付画面では FOV 20.0 cm、frequency matrix 400 なので、200 mm ÷ 400 = 0.50 mm。Phase FOV 0.88なら 176 mm、phase matrix 320なら 176 ÷ 320 = 0.55 mmで、画面表示の約0.6 mmと整合します。

理論につなげる：k-spaceの最大到達点 kmax が高いほど細かい構造を表現できます。pixel幅 Δx は概念的に Δx ≈ 1 / (2kmax)。一方FOVはk-spaceのサンプリング間隔 Δk と逆関係で FOV ≈ 1 / Δk。したがって「FOVを狭くする」と「matrixを増やす」はどちらもpixelを小さくできますが、k-spaceの取り方と時間/SNRへの代償が違います。

インタラクティブ：FOV / Matrix / Slice

In-plane pixel: 0.50 mm
概算 voxel volume: 1.25 mm³
他条件一定なら、SNRは概ねvoxel volumeに比例して増減します。

4-2. Phase FOV：時間短縮とwrapの交換条件

Phase FOVを下げると、通常はphase encode数も減らせるため時間短縮が可能です。ただし対象がPhase FOVの外まで存在するとaliasing（wrap）が起きます。

FOVphase = 1 / Δkphase

Phase FOVを半分にし、pixel sizeを保つならphase encode数もほぼ半分にできます。その代わりSNRも概ね √(収集line数の比) で低下します。

臨床：脊椎・四肢のように一方向が細長い部位では有効。腹部や肩など、FOV外の信号が入りやすい部位ではNo Phase Wrapやphase方向変更とセットで考えます。
Phase FOVを狭めすぎると、FOV外の信号が反対側へ折り返されます。

4-3. ZResとNSW：3Dで最も誤解しやすい項目

3Dでは「スライス厚」欄だけでz分解能を判断しません。GEのDICOM仕様には Actual Slice Resolution Percent と NSW Factor が個別タグとして定義されています。

添付画面では Slice 0.40 mm、ZRes 50%、画面のvoxel表示は 0.5 × 0.6 × 0.8 mm。この組み合わせは、0.40 mmが表示/再構成側の刻みでも、実収集のz方向情報量がそれより粗いことを示します。

重要：「0.4 mmで表示される = 0.4 mmの独立したz方向情報を取得している」とは限りません。MPR画質を評価する時はZRes/actual slice resolutionまで確認します。
模式図：Z方向k-spaceを部分収集し、未収集側を再構成で補うほど時間は短縮できますが、真のz方向情報量は減ります。

5. Receiver Bandwidth：SNR・chemical shift・TE・歪みを一度に動かす

5-1. GEのBW表示をHz/pixelへ変換

GEはtotal receiver bandwidthをkHzで表示します。画面のBW 31.25 kHz、frequency matrix 400なら、実画面に表示されるBW/pixel 156.2 Hz/pixelは次で再現できます。

BW/pixel ≈ (2 × 31.25 kHz × 1000) / 400 = 156.25 Hz/pixel

3Tのfat-water周波数差は約440 Hzなので、chemical shiftのずれは概算 440/156 ≈ 2.8 pixels。BW 50 kHz、matrix 380なら 263.2 Hz/pixel → 約1.7 pixelsです。

なぜSNRが落ちる？ 電子ノイズは広い周波数帯に分布します。受信帯域を広げるほど取り込むノイズ電力が増えるため、他条件一定では概ね SNR ∝ 1 / √BW。一方、sampling timeは短くなり、chemical shift・susceptibility・readout方向の歪みは減ります。

6. TR・TE・Flip Angle：コントラストを作る3本柱

TR

Mz(TR)=M0[1−exp(−TR/T1)]

TRを待つほど縦磁化が回復し、飽和が減ります。一般にTR↑でSNR↑、T1 weighting↓、時間↑。ただし3D GREやFSEなど、撮像方式によってTRの役割は異なります。

Auto TR：GE画面でAuto TRが有効な場合、coverage/sequence timingの変更でTR自体が動き得ます。「Autoだから無視」ではなく、変更後の実TRを再確認します。

TE

SE: Mxy(TE)=Mxy(0)exp(−TE/T2)
GRE: Mxy(TE)=Mxy(0)exp(−TE/T2*)

TE↑でsignalは低下し、T2/T2*差が表面化します。GREではsusceptibilityとdephasingの影響がより強く出ます。

臨床：signal不足や金属/空気近傍ではTE短縮が効くことが多い。BWを上げるとminimum TEを短縮しやすくなります。

Flip Angle

Spoiled GRE: S ∝ sinα·(1−E1)/(1−E1cosα), E1=exp(−TR/T1)

FAは励起量とsaturationを同時に変えます。3TではB1不均一とRF power/SARの影響も大きいため、単なる「明るさ調整」ではありません。

Ernst angle：定常状態SNRが最大になるFAは cos αE = exp(−TR/T1)。短TRほど最適FAは小さくなります。

Ernst angle計算

Ernst angle ≈ 11.4°

これはspoiled GREの理想化モデルです。実際の最適FAは目的コントラスト、B1、RF spoiling、sequence design、SARなどで変わります。

7. ETL・Echo Spacing・Refocus Angle：FSEの速さとぼけを決める

FSEでは1回の励起後に複数echoを収集します。ETLはecho数、Echo Spacing (ESP)はecho間隔。概念的なecho train durationは次です。

Echo train duration ≈ ETL × ESP

ETL↑でphase encodeを一気に進められるため時間は短縮しますが、echo trainの後半ほどT2減衰が進み、k-spaceの高周波成分が弱くなるとedgeが落ちてblurが増えます。

k-spaceとの結びつき：画像の「大まかなコントラスト」は中心k-space、細いエッジは外側k-spaceが担います。echoごとに信号強度が変わるFSEでは、k-space lineごとに異なるT2 decayが掛かるため、単純なFourier像ではなく「T2 decayで重み付けされたk-space」を再構成することになります。

Refocusing angleを180°より低くするとRF power/SARを下げられますが、stimulated echo pathwayの寄与、signal、contrast、blurringが変わります。3TではSAR対策として特に重要です。

8. NEX：SNRは√NEX、時間はほぼNEX

SNR ∝ √NEX
Scan time ∝ NEX

NEX 1→2でSNRは2倍ではなく約1.41倍。一方時間はほぼ2倍です。したがって、SNR不足をNEXだけで解決するのは時間効率が低いことがあります。

NEXを上げる前に確認：① voxelが小さすぎないか ② BWが広すぎないか ③ ARC/HyperSenseの加速が強すぎないか ④ AIR Recon DLでnoiseを抑えられるか ⑤ coil/position/calibrationに問題がないか。

NEXの費用対効果

相対SNR ≈ 1.00 / 相対時間 ≈ 1.0×

9. 高速化：Parallel imaging・HyperSense・AIR Recon DLは別物

GE

ASSET / ARC

Parallel imaging。複数受信coilの空間感度差を追加の位置情報として利用し、phase encodeを間引きます。

理想化：SNRacc ≈ SNRfull / (g·√R)

R↑で時間短縮。ただしSNR低下、g-factor noise、unfolding artifactが代償。ARCはautocalibrating Cartesian reconstructionで、calibration dataを撮像側に含める設計です。

GE

HyperSense

Compressed sensing。画像がある変換領域でsparseであることを利用し、incoherent undersamplingから反復再構成します。

minₓ ||Fᵤx−y||₂² + λ||Ψx||₁

前半=実測k-spaceに合うこと、後半=sparseであることを要求。GEはHyperSenseをARCと組み合わせて加速性能を高めると説明しています。

GE

AIR Recon DL

再構成/denoise・ringing低減。取得lineを単純に間引く機能ではありません。GEはraw k-spaceデータにDL reconstructionを適用し、noiseとtruncation/ringingを抑えsharpnessを高めると説明しています。

StrengthはLow/Medium/High。DICOM仕様では0.30/0.50/0.75の数値表現が定義されています。

9-1. 「Phase 2.0 × HyperSense 2.4 = 4.8倍」ではない

画面上のnominal acceleration factorは、実撮像時間短縮率と同じではありません。ACS/calibration line、k-space中心の密なsampling、sequence overhead、TR/echo train制約があるためです。結果は予測scan timeを実際に確認します。

k-spaceで考える

  • Parallel imaging：規則的にlineを間引き、coil sensitivityでunfold。
  • Compressed sensing：incoherent/variable-densityに間引き、sparsityを使って反復再構成。
  • AIR Recon DL：再構成段階でnoise/ringingを低減。取得SNRそのものと「見かけのnoise」は区別する。
強い加速 + 小voxel + 高BW + 低NEXを同時に入れると、「全部がSNRを削る方向」に重なります。DLで見た目が滑らかでも、元データの情報量が十分かを意識します。

10. GE固有・GEで重要な機能

PURE — receive coil sensitivityのむらを補正する

PURE = Phased Array Uniformity Enhancement。表面coilは近傍が明るく深部が暗くなりやすいため、calibration scanで得たcoil sensitivity情報を使い、画像の強度むらを補正します。

原理：観測画像 I(r) は概念的に「真のsignal S(r) × coil感度 C(r)」。calibrationから Ĉ(r) を推定し、I(r)/Ĉ(r) のようなbias correctionを行います。したがって深部に存在しない物理SNRを作る機能ではありません。
使う場面：phased-array coilで強度むらが読影を妨げる時。患者・coil・landmarkがcalibration後に大きく変わるとmap mismatchの原因になるため再calibrationを検討。
Prescan calibration — 「自動だから無視」ではなく、何を前提にしたかを見る

Prescanはsequence実行前の調整群の総称で、実際に行われる内容はsystem/software/sequenceで異なります。中心周波数・RF transmit・receiver gain・coil/calibration dataなど、撮像を成立させる前提を整える役割があります。

この項目だけを見て「必ず○○を校正している」と固定的に解釈しないこと。PURE/ASSETなどはcalibration dataとの整合性が重要なので、患者移動・coil位置変更・landmark変更後の挙動を確認します。
Shim Auto — B0を均一化し、FatSatと歪みの土台を作る
Δf = γ · ΔB0

B0が場所でずれると、同じ水でも共鳴周波数がずれます。これはspectral fat suppressionの失敗、GRE susceptibility、EPI distortion、局所signal lossにつながります。3Tは周波数が高く、同じppm差がHzでは大きくなるため影響が目立ちます。

見るポイント：shim volumeが目的部位に合っているか、空気/骨/金属が強い領域をどう含めているか。脂肪抑制むらを「NEX不足」と誤診しないこと。
RF Drive Mode / MultiDrive — 3TのB1不均一に対する送信側の考え方

添付画面は RF Drive Mode: Preset。GEのMultiDrive資料ではPresetとPer-Patient Optimizationの考え方が説明され、後者は短いB1 mapping/calibrationを使って患者ごとのRF amplitude/phaseを最適化します。

臨床：体格が大きい、腹水などでB1 shadingが強い、広い体幹部で均一性が悪い時に患者別最適化が有用になり得ます。ただしHeroで実際に選べるmode名・ライセンスは施設構成に依存するため、装置上の選択肢とGEマニュアルを優先してください。
AIR Recon DL Strength — Highは「取得SNRが増えた」と同義ではない

Low / Medium / Highは再構成時のnoise reduction strength。GEのDICOM仕様では0.30 / 0.50 / 0.75の表現が定義されています。

考え方：DL reconstructionは取得後のnoise/ringingを減らします。よって「物理的に受信したsignalが増える」のではなく、画像再構成後のnoise textureとsharpnessを改善します。得られた余裕を、NEX低下・薄切・matrix増加・時間短縮へ再配分できます。

11. 補正系：何を補正しているかを区別する

Flow Compensation

一定速度で動くspinのgradient-induced phaseを、追加gradient lobeで再位相化する gradient moment nulling。

φv ∝ γ · v · M1
M1 = ∫ t·G(t) dt

TE時点でM1≈0に設計すると、constant velocity成分の位相ずれを抑えます。

代償：minimum TE延長、gradient timing制約。

Motion Correction

添付画面ではMotion Correctionのcheckが見えます。PROPELLER系ではk-space中心を繰り返し通るradial blade samplingを利用し、rigid motionの影響を抑えます。

万能ではなく、大きなthrough-plane motion、非剛体運動、途中で解剖が変わる動きは残り得ます。

3D Geometry Correction

gradient nonlinearityによるwarpingを補正する機能。off-center・large FOVほどGNLの影響が大きくなります。

B0 susceptibility distortionとは別物。放射線治療計画・術前計画・定量で幾何学精度を重視する時は特に意識。

12. SAR・B1+rms・dB/dt：画面下端は「安全性のダッシュボード」

RF heating

SAR

RFによる組織への電力吸収をW/kgで評価する指標。物理的には電場によるJoule heatingが本体です。

SAR ∝ σ|E|² / ρ

3TではRF周波数が高く、B1均一性とRF power depositionの問題が1.5Tより目立ちやすくなります。

Implant RF metric

B1+rms

transmit B1+の時間RMS。

B1+rms = √[(1/T)∫|B1+(t)|²dt]

SARは患者モデル等を含む推定値ですが、B1+rmsはRF field outputをより直接的に表すため、MR Conditional implantの条件に使われます。

Gradient

dB/dt

時間変化する磁場、主にgradient switchingの速さに関係。RF heating指標ではありません。

大きなgradient amplitudeとslew rateは高速撮像に有利ですが、peripheral nerve stimulationや音響などの制約があります。

臨床でSAR/B1+rms制約に当たった時：refocusing FA低下、TR延長、RF-intensive optionの見直しなどが候補。ただしcontrast、時間、echo pathwayと交換です。MR Conditional implantではメーカー条件を厳密に優先し、SARとB1+rmsを自己流で読み替えないでください。
