MRI Advanced Imaging Principles

パラレルイメージング（Parallel Imaging）徹底マスター

位相アレイコイルの局所空間感度差を利用してk空間を間引き、画質トレードオフを制御しながら撮像時間を劇的に短縮する中核技術

パラレルイメージング（PI）とは何か？

パラレルイメージング（PI）とは、複数の小型受信コイルエレメントを並列配置した位相アレイコイル（Phased Array Coil）を用い、各コイルが持つ独自の「空間感度差（感度プロファイル）」を空間位置の識別に利用することで、k空間の位相エンコード行を間引いて撮像時間を短縮する技術です。

  • 「パラレル」の由来：複数のコイルエレメントが被写体からのMR信号を同時かつ並列（Parallel）に受信することから命名されました。
  • 基本動作：位相エンコードステップを1行おき（加速因子 R=2）や2行おき（R=3）にスキップして収集します。
  • エイリアシングの必然性：サンプリング間隔が広がるため、ナイキスト基準を下回り、そのままフーリエ変換すると位相エンコード方向に画像が重なり合う「折り返し（エイリアシング）」が発生します。
  • 復元の鍵：各コイルに近い部位は信号が強く、遠い部位は弱いという「感度差」を連立方程式または畳み込み演算で解き、折り重なったピクセルを正規の位置へと分離（アンラップ）します。

臨床を二分する2大方式：SENSE と GRAPPA

パラレルイメージングは、「どこで折り返しを復元するか」によって大きく2系統に分かれます。実空間（画像領域）で連立方程式を解くSENSEと、周波数空間（k空間領域）で抜けたデータを埋めるGRAPPAです。

復元処理を行う領域 実空間（Image Domain） k空間（Frequency Domain）
感度情報の取得方法 プレスキャン（事前低分解能撮像） ACSライン（本スキャンk空間中心部の密収集）
アルゴリズムの概要 各コイルの折り返し画像から、感度マップ行列の逆行列を解いて重なりを展開する 取得済みの周囲k空間データから線形結合重み（Kernel）を求め、欠落ラインを補間充填する
実効的な高速化率 設定Rがそのまま撮像時間短縮に直結 中心部のACS収集時間があるため、実効Rは若干低下（例: 2.0 → 約1.9）
体動・呼吸への耐性 プレスキャン時から被写体が動くと感度不一致で残存ゴーストが出やすい 本スキャンと同時にキャリブレーション行を収集するため、動きに強い

SENSEの数学的メカニズム（コイル2個・R=2の場合）

加速因子2のとき、折り返されたピクセル信号 $A_1, A_2$ は、FOVの1/2離れた真の組織信号 $O_1, O_2$ が各コイルの局所感度 $S$ で重み付けされて合算されたものです。

{ A1 = S11O1 + S12O2 A2 = S21O1 + S22O2

※ 未知数2つ（$O_1, O_2$）に対し、独立したコイル感度をもつ方程式が2つあるため、逆行列計算によって真の信号 $O_1, O_2$ が一意に分離されます。

物理・数学的原理：PIにおけるSNR低下の法則

パラレルイメージングを適用すると、撮像時間が短縮される代償として必ず信号雑音比（SNR）が低下します。この関係は以下の厳密な数式で記述されます。

SNR PI = SNR0 g ⁢ R
  • 各記号の意味と単位：
    • SNRPI：パラレルイメージング適用後の画像SNR（無次元比）
    • SNR0：間引きを行わない通常スキャン時の画像SNR（無次元比）
    • R：加速因子（Reduction factor / Acceleration factor, 1以上の実数）
    • g：幾何学的配置因子（Geometry factor / g-factor, 局所空間変数, g≥1）
  • 比例・反比例関係： SNRPI は 加速因子の平方根 R に反比例 し、さらに g因子に反比例 します。
  • 変数の増減と物理的意味：
    • 1/R 成分：収集する位相エンコード行数が 1/R に減少することによる、純粋なサンプリング時間短縮に伴う統計的ノイズの増加です（例: R=2 のとき必然的に約 1/2≈71% に低下）。
    • g 因子成分：コイルエレメント同士の空間感度プロファイルの重なり合いの悪さ（数学的直交性の低さ）によるノイズ増幅です。画像の中央部や被写体の深部など、コイル間の感度差が小さくなる領域ほど g>1 となり、局所的にSNRが極端に悪化します。
加速因子R設定の臨床ルール
加速因子Rをコイルチャンネル数に近づけすぎたり無理に高く設定すると、g因子が指数関数的に爆発し、画像中央部に激しい砂嵐状のノイズバンドが出現します。通常のルーチン臨床では R=2（多くてもR=3程度）が実用上の黄金律とされます。
臨床現場でパラレルイメージングが不可欠な場面

PIは単に「検査を早く終わらせる」だけでなく、動く臓器の静止画化、歪み抑制、アーチファクト克服など、画質そのものを根底から向上させる目的で日常臨床に深く組み込まれています。

臨床シーン・シーケンス PIを使用する技術的理由・臨床的メリット
腹部造影ダイナミックMRI
(肝細胞癌・膵臓など)		 動脈相（Early/Late arterial phase）の血流灌流はわずか数秒〜十数秒で推移します。PI（R=2〜3）により息止め撮像時間を20秒以下に短縮し、患者の呼吸停止限界内で血流ピークを確実に捉え、呼吸体動ブレを完全に排除します。
頭部・体幹部 拡散強調画像
(DWI: Single-shot EPI)		 EPIは位相エンコード方向の帯域幅が極めて狭く、磁化率不均一による幾何学的歪みやN/2ゴーストが多発します。PIによってエコートレイン長（ETL）とエコースペースを短縮することで、位相誤差の蓄積を防ぎ、頭蓋底・前立腺・頸部での画像の歪みとボケを劇的に改善します。
3D 造影・非造影 MRA
(頸部・下肢・腎動脈など)		 3次元収集は膨大な位相エンコードステップを要するため、通常では10分以上かかります。PIを位相軸およびスライスエンコード軸（2D-PI）に適用することで、高精細な等方性ボクセル（微小動脈瘤・狭窄の描出）を数分の現実的な時間で撮像可能にします。
心臓シネ・遅延造影（LGE）
(TrueFISP / FIESTA)		 心拍同期下において、1心拍あたりに収集できるビュー数（Views per segment）をPIで圧縮。1回の息止めで左室駆出率（EF）や心筋壁運動を極めて高い時間分解能で評価できます。
3テスラ超高磁場MRIでの撮像
(全身領域)		 3TではRFエネルギーによる生体内組織発熱（SAR: 比吸収率）が1.5Tの約4倍に急増します。PIを併用してRF照射パルス総数を減らすことで、SAR制限に引っかからずにTRやスライス枚数を最適化できます。また3Tは元々のSNRが高いため、PIによるSNR低下を相殺しやすい理想的な組み合わせです。
臨床トラブルシューティング：PI特有のアーチファクトと回避策
  • 中央部の帯状ノイズ（g-factor noise）： コイルの感度重複が大きい深部で局所SNRが急低下する現象。
    【対策】 加速因子Rを下げる（例: R=3 → R=2）、チャンネル数の多い最適コイル（32ch以上）を使用する、加算回数（NEX）を補う。
  • 残存エイリアシングゴースト（Residual Aliasing）： 折り返しが消え切らず、薄いゴーストとして画面に残る現象。SENSEではプレスキャン後の患者体動、GRAPPAではACSライン不足が原因となります。
    【対策】 プレスキャンの直前再取得、体動抑制の徹底、ACS収集行数（Auto-calibration lines）の増大。
  • 小FOV撮像での計算破綻： 関心部位のみを狭いFOVで撮像した際、被写体の外側の信号が巻き込んで感度行列が解けなくなる。
    【対策】 SENSE系よりもk空間補間を行うGRAPPA系（ARC等）を選択するか、No Phase Wrap（過剰サンプリング）を併用する。
