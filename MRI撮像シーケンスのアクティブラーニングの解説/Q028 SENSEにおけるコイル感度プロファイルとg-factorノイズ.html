出題（問題文原文）
SENSEでコイル感度プロファイルが互いに似すぎていると、なぜg-factorノイズが増えるのですか。
予測メモ：連立方程式が解きにくくなる。
ユーザー解答
「SENSEはパラレルイメージングの間引いた信号を実空間上で補正して信号を埋めるための技術である。コイル感度プロファイルが互いに似すぎていると、実空間上で隣同士の信号が似ているため補正が上手く働かなくなる。結果、幾何学配置因子gが大きくなる。」

正しく理解できた点

SENSEが実空間（画像領域）においてコイル感度を用いてエイリアシング（折り返し）を分離する技術であること、および感度の不良が「幾何学的配置因子（g-factor）」の増大をもたらす帰結を捉えています。何より、予測メモにあった「連立方程式が解きにくくなる」という発想は、数学的本質を100%射抜いています。

最大の修正点

「実空間上で隣同士の信号が似ているため」という表現は物理的に誤りです。似通っているのは「隣り合う生体組織の信号（コントラスト）」ではなく、重なり合った画素位置における「各コイル素子の空間的感度（方程式の係数比）」です。被写体の信号値自体が似ているかどうかは無関係です。

根本的誤概念（克服すべきポイント）

「被写体の信号同士が似ていて見分けがつかない」と考えてしまう落とし穴です。SENSEは折り重なった位置ごとに異なる「コイル感度の勾配（独立性）」を係数として連立方程式を解きます。コイル感度同士が似通うと、感度行列の列ベクトルが平行（線形従属）に近づき、行列式（連立方程式の分母）が 0 に近づきます。その結果、逆行列を計算する際に微小な測定ノイズが「0で割り算」されるような状態になり、画素値のノイズが天文学的に跳ね上がります。

模範解答
SENSEでは位相エンコード間引きにより同一画素に折り重なった複数の信号を、各コイル素子の「感度プロファイルの違い」を係数とする連立一次方程式を解いて分離する。コイル感度プロファイルが互いに似すぎていると、感度行列の列ベクトル同士が線形従属に近づき、行列式がゼロ近傍となる（悪条件問題）。この連立方程式を解く逆演算を行う際、各コイルに含まれる微小な熱雑音が「ほぼゼロの分母」で割られるように爆発的に増幅されて画素値へ伝播する。このノイズ増幅率を表す幾何学的配置因子（g-factor ≥ 1）が極端に大きくなるため、画像上に激しいノイズが発生する。

【超初級解説】中学・高校の連立方程式で完全にわかるg-factorの正体

「行列やテンソルが出てくると頭が痛くなる…」という方のために、まずは中学数学の「2元1次連立方程式」だけで、なぜ感度が似るとノイズが爆発するのかを完全に紐解きます。

ステップ 1 SENSEを身近な連立方程式で表す

加速係数 R = 2（撮像時間を半分にして視野を半分に間引いた状態）を考えます。このとき、実空間のある1つの画素には、本来離れた場所にある「位置1の信号 m1」と「位置2の信号 m2」が重なり合って届きます。

いま、受信コイルが2個（コイルA、コイルB）あるとします。各コイルが受信する信号（sA,sB）は、それぞれの位置でのコイルの感度（感度を C とします）で重み付けされた合計値になります：

{ CA1m1+CA2m2=sA+nA（コイルAの受信信号） CB1m1+CB2m2=sB+nB（コイルBの受信信号）

※ nA,nB は受信回路や人体から混入する避けられない微小な熱雑音（ノイズ）。

ステップ 2 中学数学（加減法）で未知数 m1 を解く（途中式を一切省かない計算）

m2 を消去するために、上の式に CB2 を掛け、下の式に CA2 を掛けて引き算します：

CB2(CA1m1+CA2m2) = CB2(sA+nA) -)CA2(CB1m1+CB2m2) = CA2(sB+nB) ──────────────────────────────────────────────────── (CA1CB2-CA2CB1)m1 = (CB2sA-CA2sB)+(CB2nA-CA2nB)

両辺を (CA1CB2-CA2CB1) で割ると、求めたい真の画素値 m1 の解が得られます：

m1 = CB2sA-CA2sBCA1CB2-CA2CB1▲本来の復元信号成分 + CB2nA-CA2nBCA1CB2-CA2CB1▲画像上に現れるノイズ成分！
ステップ 3 「感度プロファイルが似る」と何が起きるか？

上式の分母 CA1CB2-CA2CB1 に全神経を集中してください。

  • コイル感度が大きく異なる場合（理想状態）：
    例えばコイルAは位置1に極めて近く（感度1.0）、位置2からは遠い（感度0.1）。コイルBは逆に位置1から遠く（感度0.1）、位置2に近い（感度1.0）とします。
    分母は 1.0×1.0-0.1×0.1=0.99 となり、分母がしっかり大きな値を持つため、ノイズ成分は増幅されません。
  • コイル感度プロファイルが似すぎている場合（問題の状態）：
    深部臓器やコイル配列の向きが悪く、コイルAもコイルBも位置1と位置2に対する感度変化がほとんど同じ（例えば CA1=0.50,CA2=0.49,CB1=0.50,CB2=0.49）だとします。
    すると分母は：
    分母 ＝ 0.50 × 0.49 − 0.49 × 0.50 ＝ 0.0000… （ほぼゼロ！）
!
ノイズ爆発のメカニズム：
分母が「ほぼゼロ（0.001など）」になると、ノイズ項の計算は 「微小な雑音 ÷ 0.001 ＝ 雑音が1000倍に巨大化！」 されることになります。受信機が拾ったわずかな熱雑音（nA,nB）が数千倍に跳ね上がって画素値 m1 に上乗せされてしまうのです。このノイズの拡大係数こそが g-factor（幾何学的配置因子） です。

【数理厳密解説】方程式系２の完全導出：逆行列演算からg-factorの定義まで

前の章で直感的に掴んだ「分母がゼロに近づいてノイズが爆発する」という現象を、任意のコイル数・加速率に対応できるよう行列代数（線形代数）と統計学（誤差伝播）を用いて1つの省略もなく完全に導出します。

導出 A 観測方程式（フォワードモデル）の行列表現

コイル素子数を Nc、加速率（重なり合う画素数）を R とします（ただし解が存在するために Nc≥R）。あるエイリアスした画素における観測方程式は次のように書けます：

s=Cm+η
・s∈CNc×1：各コイルが受信した重なり画像の値（既知の測定値ベクトル）
・C∈CNc×R：事前計測されたコイル感度行列（既知の係数行列）。Cγρ は位置 ρ に対するコイル γ の複素感度
・m∈CR×1：分離したい真の画素値ベクトル（未知数）
・η∈CNc×1：受信熱雑音。平均ゼロ、共分散行列 Ψ=E[ηηH] に従うガウス雑音
導出 B アンフォールディング逆行列 W の決定（重み付き一般化逆行列）

重なりを解く再構成画像 m^ を、観測ベクトル s に対する線形フィルタ行列 W∈CR×Nc を用いて次のように作るとします：

m^=Ws

ここで、次の2つの絶対条件を課します：

  1. 不偏性（折り返し信号を完全除去すること）： ノイズがないとき m^=W(Cm)=m となる必要があるため、WC=I（単位行列）でなければならない。
  2. 最小分散（画像ノイズを最小化すること）： コイル間のノイズ相関 Ψ を考慮した重み付き二乗誤差を最小にする。

ガウス・マルコフの定理（Gauss-Markov Theorem）より、この条件を満たす最良線形不偏推定量（BLUE: Best Linear Unbiased Estimator）の再構成行列 W は一意に定まります：

W = (CHΨ-1C)-1 CH Ψ-1

検算：WC=(CHΨ-1C)-1(CHΨ-1C)=I となり、確かに折り返しは完全に消去されます。

導出 C 復元画素 m^ のノイズ共分散行列の計算（ノイズの伝播）

推定解 m^ に観測式 s=Cm+η を代入します：

m^ = W(Cm+η) = WCm=m + Wη = m+Wη

この第2項 Wη が、再構成画像に混入する誤差（ノイズ）です。このノイズの共分散行列 Xm を計算します：

Xm = E[(Wη)(Wη)H] = WE[ηηH]WH = WΨWH

ここに先ほど求めた W=(CHΨ-1C)-1CHΨ-1 を代入して展開します：

Xm = [(CHΨ-1C)-1CHΨ-1]Ψ[(CHΨ-1C)-1CHΨ-1]H = (CHΨ-1C)-1CHΨ-1ΨΨ-1=Ψ-1C(CHΨ-1C)-1 = (CHΨ-1C)-1(CHΨ-1C)=I(CHΨ-1C)-1 = (CHΨ-1C)-1

驚くほど美しい結果が得られました。復元された各画素のノイズ分散（標準偏差の二乗 σSENSE,ρ2）は、この行列の対角成分そのものになります：

σSENSE,ρ2 = [Xm]ρρ = [(CHΨ-1C)-1]ρρ
導出 D フルサンプリングSNRとの比較と g-factor の定義

一方、パラレルイメージングを使わずに全位相エンコードを収集した通常画像（Full Fourier）を、最適合成法（Roemer合成）で結合したときの画素分散は次のようになります（サンプリング点数が R 倍多いため）：

σfull,ρ2 = 1R⋅(CHΨ-1C)ρρ

両者の標準偏差の比（ノイズが何倍に悪化したか）を計算します：

σSENSE,ρσfull,ρ = σSENSE,ρ2σfull,ρ2 = R ⋅ [(CHΨ-1C)-1]ρρ⋅(CHΨ-1C)ρρ▲これこそが幾何学的配置因子gρの厳密な定義！

SNR=信号/σ であるため、SENSEにおけるSNR低下の基本公式が完全に証明されました：

SNRSENSE,ρ = SNRfull,ρR⋅gρ
ℹ
初学者が絶対に知っておくべきSNR低下の2重構造：
① R の損失（物理的限界）： 計測時間を 1/R に短縮したため、収集データ点数が減少し、統計的な平均化効果が失われることによる必然の低下。
② g-factor の損失（数学的ペナルティ）： 連立方程式の逆行列を解く際に、コイル感度の似通い（平行性）によってノイズが増幅されるペナルティ。g≥1 であり、感度が完全に直交しているときのみ理想の g=1 となります。

臨床現場で「感度が似てg-factorノイズが爆発する」具体的場面

臨床シチュエーション なぜコイル感度が似てしまうのか 画像上の現象・アーチファクト 現場での最適化・回避プロトコル
① 位相エンコード（PE）方向のミスマッチ
例：腹部や頭部での方向選択誤り 		コイル素子は通常「左右（R-L）」に並んでいる。ここでPE方向を「前後（A-P）」に設定すると、折り重なる2点（前と後）から各コイル素子までの距離が左右対称でほぼ等しくなり、素子間の感度プロファイル差がつかなくなる。 画像の中央帯（位相折り返し中心線上）に、ザラザラとした激しい帯状ノイズ（Noise Band）が吹き出す。 PE方向をコイル素子が並んでいる方向（左右方向）に変更する。アレイ素子の幾何学的配置とPE軸を一致させる。
② 体深部・中心部臓器の撮像
例：前立腺、膵臓、腹部大動脈、胸腰椎深部 		表面アレイコイルは体表直下では感度差が急峻（直下は強く隣は弱い）だが、深部中心部へ進むほど全素子から等しく遠ざかり、どの素子でも感度が平坦化（フラット）して差が消滅する。 体表の皮下脂肪は高画質なのに、観察したい体深部・脊椎・前立腺実質のみが激しい砂嵐状ノイズに埋没する。 深部撮像時はSENSE加速率を下げる（R=2 → 1.5や1.3）。またはk空間中央を自己較正するARC/GRAPPAやCompressed Sensing（HyperSense等）を併用する。
③ 過大な加速係数（R倍速の壁）
例：息止め短縮を狙ったR=3〜4設定 		間引き率 R を 3 や 4 に上げると、実空間で近接した狭いピッチの点同士が重なり合う。近接画素間ではコイル感度の勾配（変化率）が極めてわずかしかないため、感度行列の列ベクトル同士が強烈に相関する。 g-factor が局所的に 3〜5 以上に跳ね上がり、SNRが 1/( √R · g ) に従って 1/6〜1/10 以下へ劇的に崩壊する。 2D撮像では実用限界（多くはR=2まで）を守る。3D撮像において2軸方向（位相方向 × スライス方向）に加速を分散（2D SENSE：例 1.5 × 1.5）させる。
④ プリスキャン時と本スキャンの体動ズレ
例：呼吸停止レベルの不一致 		SENSEはスキャン前の「低分解能キャリブレーション（感度マップ取得）」に完全依存する。息止め位置がズレたり体動が入ると、方程式を解くための感度係数 C と実際の被写体位置が乖離し、解が破綻する。 不自然なエッジのゴースト、折り返し信号の消し残り、特定スライス全体に広がる雪嵐状のノイズ。 Calibration in PreScanの設定を確認し、自由呼吸と息止めスキャンが混在するプロトコルではキャリブレーションの引き継ぎを切り離す（息止めシリーズ単独で再計測）。
