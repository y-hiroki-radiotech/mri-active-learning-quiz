1. 出発点：この式は何を意味しているのか

PC-MRAの物理的・数学的基盤となる最も根源的な式は、等速直線運動をするスピンが傾斜磁場下で蓄積する追加位相の式です。

Δ ϕ = γ v ∫ 0 t τ G ( τ ) d τ
【基本方程式1】速度に依存して生じる正味の位相シフト
記号 名称 物理的意味 単位 比例・依存関係
Δϕ 位相シフト 速度運動によって静止状態から追加で蓄積される位相角 rad （ラジアン） 流速 v およびモーメント M1 に直接比例
γ 磁気回転比 核種固有の定数（¹H プロトンでは約 2.675×108rad/(s⋅T)） rad/(s⋅T) 物理定数（固定）
v スピン速度 傾斜磁場印加軸に沿った流体（血液・髄液）の等速流速 cm/s または m/s 測定対象。増大すると位相シフトが線形に増大
G(τ) 傾斜磁場波形 時刻 τ において印加されている磁場勾配の強さ mT/m または T/m パルスシーケンス設計値
τ 時間変数 傾斜磁場印加開始（0）から現在までの経過時間 s （秒） 積分パラメータ（時間の重み付け要因）

この積分項は、MRI物理学において傾斜磁場の1次モーメント（First Moment of Gradient: M1）と定義されます。

M 1 = ∫ 0 t τ G ( τ ) d τ

したがって、基本式は極めてシンプルに次の積として記述されます：

Δ ϕ = γ v M 1

2. そもそもなぜ速度で位相が変わるのか（完全導出）

【基本原理：位相と角周波数積分の関係】
位相 ϕ(t) は、基準角周波数（ラーモア周波数 ω0）からの周波数ずれ Δω(τ) の時間積分によって蓄積されます。
  1. 局所磁場変化と角周波数シフトの定式化
    位置 x(τ) にあるスピンが傾斜磁場 G(τ) を受けるとき、主磁場からのズレは：
    Δ B ( τ ) = G ( τ ) x ( τ )
    ラーモアの法則（ω=γB）より、角周波数のズレは：
    Δ ω ( τ ) = γ Δ B ( τ ) = γ G ( τ ) x ( τ )
  2. 位相積分の展開
    全位相 ϕ(t) はこれを時間積分したものです：
    ϕ ( t ) = ∫ 0 t Δ ω ( τ ) d τ = γ ∫ 0 t G ( τ ) x ( τ ) d τ
  3. 運動方程式の代入（等速直線運動の仮定）
    スピンが初期位置 x0 から速度 v で等速直線運動しているとすると：
    x ( τ ) = x 0 + v τ
    これを位相積分式に代入します：
    ϕ ( t ) = γ ∫ 0 t G ( τ ) ( x 0 + v τ ) d τ
  4. 積分の分配と定数の括り出し
    括弧を展開し、時間 τ に依存しない定数 x0 と v を積分の外へ出します：
    ϕ ( t ) = γ x 0 ∫ 0 t G ( τ ) d τ + γ v ∫ 0 t τ G ( τ ) d τ
  5. 0次および1次モーメントの定義
    ここで、傾斜磁場の0次モーメント（面積）M0 と1次モーメント M1 を定義します：
    M 0 = ∫ 0 t G ( τ ) d τ M 1 = ∫ 0 t τ G ( τ ) d τ
    したがって、位相は完全に以下の2成分の和として表されます：
    ϕ ( t ) = γ x 0 M 0 【位置による位相】 + γ v M 1 【速度による位相】

3. PC-MRAは何をしているのか & 4. 双極性傾斜磁場の図解

PC-MRAの目標は極めて明快です。「静止した組織の位相をゼロにし、動いている血流だけに速度に比例した位相を与える」ことです。

【PC-MRAの傾斜磁場条件】
① 静止スピンをゼロに： M0=0 ② 速度スピンに位相を： M1≠0

M0=0 とすれば、位置による項 γx0M0=0 となり、静止している脳実質や筋肉などの位相は完全にキャンセルされます。残るのは血流速度 v に比例する ϕ=γvM1 のみとなります。

5. PC-MRAでは実際には2回撮る & 6. PC-MRAの中心式

実際の臨床MRIでは、静磁場不均一（ΔB0）や化学シフト、渦電流による位相誤差が存在するため、単一の撮像では流速の位相だけを純粋に取り出すことができません。 そこで、「速度エンコード状態を変えて2回撮像し、複素位相の差分をとる」手法が用いられます。

対称ペア（±M₁）による差分の完全導出過程

1回目のエンコード（+M₁）で得られる位相：

ϕ + = ϕ error + γ v M 1

2回目のエンコード（極性を反転させた -M₁）で得られる位相：

ϕ − = ϕ error + γ v ( − M 1 ) = ϕ error − γ v M 1

両者の位相差 Δϕ を計算すると、装置背景誤差 ϕerror が完全に相殺されます：

Δ ϕ = ϕ + − ϕ − = [ γ v M 1 ] − [ − γ v M 1 ] = 2 γ v M 1

一般化して、2回の1次モーメント差を ΔM1=M1,+−M1,− と置くと、PC-MRAの中心式が得られます：

Δ ϕ = γ v Δ M 1
【PC-MRA中心方程式】位相差から血流速度への変換式

両辺を γΔM1 で割れば、測定された画像上の位相値 Δϕ から直接速度 v が計算できることが分かります：

v = Δ ϕ γ Δ M 1

7. ここでVENCが登場する & 8. VENCの厳密な導出

【VENC (Velocity Encoding) の臨床的・物理的定義】
MRIの位相画像において折り返し（aliasing）を起こさずに一意に表現できる最大位相差は ±π（±180∘） です。
したがって、「位相差がちょうど +π に達する速度限界値」 を VENC と定義します。

【VENC公式の完全導出】

中心式 Δϕ=γvΔM1 において、v=VENC のとき Δϕ=π となるため：

π = γ ⋅ VENC ⋅ Δ M 1

両辺を γΔM1 で割ると、基本式が得られます：

VENC = π γ Δ M 1
【VENC一般決定式】

対称な ±M1 ペアの場合、ΔM1=2M1 ですので：

VENC = π 2 γ M 1

9. 速度と位相差の直感的な相互換算式

上式より γΔM1=πVENC ですので、これをもとの式に代入します：

Δ ϕ = π v VENC ⇔ v = Δ ϕ π VENC
【臨床用換算式】位相角と血流速度の比例関係

12〜16. VENC設定の数理的トレードオフ（感度・ノイズ・折り返し）

VENCをどのように決定すべきかは、PC-MRAにおける最大の臨床的命題です。これは単なる経験則ではなく、微積分と統計的ノイズ伝播式 から完全に説明できます。

① 感度（傾き）の数学的証明

位相差の速度に対する微係数（感度・傾き）を計算します：

d ( Δ ϕ ) d v = d d v ( π v VENC ) = π VENC
  • VENCが小さい（低VENC）：傾き πVENC が急激になるため、微小な速度変化でも大きな位相差として鋭敏に検出（超高感度）されます。
  • VENCが大きい（高VENC）：傾きが緩やかになり、同じ速度差であっても生じる位相差がわずかしか得られず、感度が鈍化します。

② 速度ノイズ（流速分解能）の統計的証明

画像上の複素信号に含まれる位相ノイズ（標準偏差）を σϕ とすると、換算される流速ノイズ σv は誤差伝播の法則より：

σ v = σ ϕ VENC π ⇒ σ v ∝ VENC

17. 強度画像と位相画像 & 18. 3次元ベクトル拡張

PC-MRAでは、1回の収集から性質の異なる2系統の画像を再構成して診断を行います。

① 強度画像（Magnitude Image）

複素差分信号の絶対値（振幅）を描出した画像です。
静止組織は信号が相殺されて無信号（真っ黒）となり、流速の大きさ（スピード）に比例して血管内腔が明るく高信号（白）に浮き上がります（通常のMRA形態診断に直結）。

② 位相画像（Phase Map / 速度画像）

各位素の位相角 Δϕ を白黒の階調に変換した画像です。
静止組織はゼロ（灰色）、順方向の流れは白（高信号）、逆方向の流れは黒（低信号）として描出され、流れの向き（右/左、上/下、前/後）と定量的速度を完全評価できます。

18. ベクトル方程式としてのPC-MRA

血流速度および印加傾斜磁場は本来3次元ベクトルです。内積形式で一般化すると：

Δ ϕ = γ v ⋅ Δ M 1 = γ ( v x Δ M 1 x + v y Δ M 1 y + v z Δ M 1 z )

したがって、傾斜磁場を印加した軸方向の速度成分のみが選択的にエンコードされます。3軸方向（X, Y, Z）に順次エンコードを行う3方向PC（4-point法など）を用いることで、空間内の真の血流ベクトル場（4D Flow MRIなど）を完全にマッピングすることが可能になります。

【19. 臨床現場におけるVENC決定黄金律】
VENC設定の鉄則は：
「測定対象の予想最大流速の 1.1 〜 1.3倍（10〜30%上）に設定する」
ピーク流速を下回るとaliasingを起こし、過度に高すぎると速度ノイズ σv が増大して微小な血管病変や遅い拡張期流が見えなくなるため、この安全マージンが最適となります。
