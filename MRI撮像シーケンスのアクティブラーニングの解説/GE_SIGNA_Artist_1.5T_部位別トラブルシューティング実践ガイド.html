1. 頭部（脳）

添付「部位別MRI」から課題を抽出

添付資料では、後頭蓋窩DWIの歪み、FLAIRのCSF抑制・拍動、SWI/SWANのsusceptibilityと体動が主な再撮像ポイント。

撮像開始前の基準：全脳coverage、左右対称、DWI/ADCの位置対応を最初に確認。

後頭蓋窩DWIが歪む／ADCとT2の解剖位置が合わない

まず確認：患者固定 → Shim/Prescan → EPIの歪み方向とBWを確認
動かす/確認するパラメータ操作の方向なぜ効くか代償・注意
Shim = Auto / Prescan Calibration 再shim・prescanをやり直す。特に頭位置変更後。 off-resonanceを減らしてEPIの幾何学歪みを抑える 再調整時間が増える
Bandwidth 可能なら広げる 1 pixel当たりの周波数幅が広がりoff-resonanceによる位置ずれが減る SNR↓
Freq. Encode Direction phase方向が病変へ歪みを重ねる場合は方向変更を検討 EPIの歪み・ghostが展開する方向を病変から逃がせる 別方向に歪みが移る。wrap条件も変化
FOV / Phase FOV 小さすぎるFOVを見直す 位相方向のaliasingと局所的な歪みの見かけを軽減 分解能↓または時間↑
シーケンス固有の追加策：parallel imaging / segmented EPIが使える場合は併用候補。これはシーケンス固有設定で、今回の4枚の基本コンソール画面外。
再撮像の判定：ADCで病変位置がT2/FLAIRと解剖学的に一致するか。

FLAIRで脳室周囲や後頭蓋窩にCSF拍動ghostが重なる

まず確認：ghostの方向を確認し、phase方向を推定する
動かす/確認するパラメータ操作の方向なぜ効くか代償・注意
Freq. Encode Direction frequency方向を90°変更してphase方向を変える ghostを診断対象から逃がす wrap・chemical shiftの方向も変わる
Flow Compensation 使用可能ならflow補正方向を検討 一定速度成分の位相分散を軽減 minimum TE延長・gradient負荷
NEX SNRに余裕があり時間が許せば増やす ランダム成分の平均化 時間↑。周期性ghostは完全には消えない
ETL / Echo Spacing blurや時間も問題ならETL/ESPを併せて再評価 FSEの時間とPSFを調整 ETL↑でblur↑
シーケンス固有の追加策：必要に応じSAT bandや専用flow対策を追加。
再撮像の判定：別断面でも同じ髄内/脳実質高信号が再現するか。

体動が強く、長いFSE系が成立しない

まず確認：固定・説明・短時間化を優先。パラメータはその次。
動かす/確認するパラメータ操作の方向なぜ効くか代償・注意
Phase Matrix 必要最小限へ下げる phase encode数を減らして短時間化 in-plane分解能↓
NEX 過剰なら下げる 撮像時間短縮 SNR↓
ETL 許容範囲で増やす 1TRあたり多くのlineを取得 T2 blur↑
Recon DL strength 使用可能なら強度を上げ、SNR余裕を短時間化へ回す NEX↓やmatrix調整のSNR損失を補いやすい 質感変化。施設評価が必要
シーケンス固有の追加策：必要に応じPROPELLER等のmotion-robust acquisitionへ変更。
再撮像の判定：短時間化した結果、病変検出に必要なvoxelサイズを失っていないか。

2. 頸部軟部組織・頸椎

添付「部位別MRI」から課題を抽出

添付資料では、嚥下・呼吸・拍動・歯科金属・空気境界、下頸部の脂肪抑制ムラ、頸髄CSF pulsationが主要課題。

撮像開始前の基準：鎖骨上窩までのcoverage、頸椎では大後頭孔〜T1と椎間板に沿う断面を確認。

嚥下ghostが咽頭・喉頭病変に重なる

まず確認：嚥下指示と撮像時間を見直し、そのうえでghost方向を変える
動かす/確認するパラメータ操作の方向なぜ効くか代償・注意
Freq. Encode Direction phase方向を病変から外す向きへ変更 嚥下ghostの走行方向を移す wrap方向も変わる
Phase FOV / No Phase Wrap 方向変更後に必要なphase coverageを再設定 不要なphase FOVを減らして時間短縮 小さすぎるとwrap
Phase Matrix 必要なら少し下げる 撮像時間短縮 分解能↓
ETL FSEで許容範囲内に増やす 短時間化 blur↑
シーケンス固有の追加策：長いFSEで成立しない場合はPROPELLERなどを検討。
再撮像の判定：ghostを消すより『病変から逃がせたか』を確認。

下頸部・肩近傍で脂肪抑制が片側だけ効かない

まず確認：B0不均一を疑う。CHESSの強さだけを触らない。
動かす/確認するパラメータ操作の方向なぜ効くか代償・注意
Shim = Auto shim volumeと中心位置を見直して再shim fat-water周波数選択の前提となるB0均一性を改善 広い頸部では完全均一化は困難
Prescan Calibration coil/landmark変更後なら再取得 center frequency・RF関連の再調整 追加時間
PURE 濃淡むらならcalibrationとcoil位置を確認 受信感度むらを補正 脂肪抑制そのものは直さない
Bandwidth 必要に応じ広げる off-resonance影響を小さくする SNR↓
シーケンス固有の追加策：B0不均一が強い場合はDixon/STIRへ切替える方が安定することがある。
再撮像の判定：脂肪抑制の均一性と病変コントラストを別々に評価。

頸髄T2でCSF拍動が髄内高信号のように見える

まず確認：SagittalとAxialで再現性を確認
動かす/確認するパラメータ操作の方向なぜ効くか代償・注意
Freq. Encode Direction phase ghostを脊髄から外す方向へ 拍動ghostの位置を変更 他のartifact方向も変化
Flow Compensation 利用可能ならslice/readout方向を検討 flow-related phase dispersionを軽減 TE延長
FOV / Matrix 脊髄のvoxelサイズを再確認 大きすぎるvoxelによるpartial volumeを回避 高分解能化でSNR↓
シーケンス固有の追加策：必要に応じSAT band。1断面だけの高信号はartifactを強く疑う。
再撮像の判定：髄内病変なら別断面でも位置整合性があるか。

C7/T1だけSNRが落ちる

まず確認：coil位置・肩の位置・患者中心を確認
動かす/確認するパラメータ操作の方向なぜ効くか代償・注意
Slice Thickness 診断上許容できれば少し厚く voxel volume↑でSNR改善 through-plane分解能↓
Matrix 過剰高matrixなら下げる voxel↑でSNR改善 分解能↓
Bandwidth artifactに余裕があれば少し狭める SNR↑ chemical shift / distortion↑
Recon DL / NEX Recon DLを活用、必要ならNEX↑ SNR補償 NEX↑で時間増
シーケンス固有の追加策：まずコイル感度域に頸胸移行部が入っていることが前提。
再撮像の判定：Relative SNRだけでなく実画像のC7/T1 cord-to-CSF contrastを確認。

腰椎で腹部motion ghostが脊柱管に入る

シーケンス固有の追加策：anterior saturationも有効なことがある。

術後腰椎で金属周囲が広くsignal loss / distortion

まず確認：通常FSEか、金属低減sequenceが必要かを判断
動かす/確認するパラメータ操作の方向なぜ効くか代償・注意
Bandwidth 広げる off-resonanceによる位置ずれ・chemical shiftを縮小 SNR↓
Slice Thickness 薄くする through-plane dephasing / partial volumeを軽減 SNR↓

Subtractionに広範な偽増強が出る

6. 腹部（肝・膵胆道・腎副腎）

Phase Matrix 下げる 時間短縮 分解能↓
Phase FOV 左右/前後の身体幅が許せば縮小 phase encode削減 wrap↑
NEX 不要なaveragingを削る 時間短縮 SNR↓
Slice Thickness 少し厚くしてSNR余裕を作る より強いacceleration/短時間化を許容 小病変のpartial volume↑
シーケンス固有の追加策：parallel acceleration、multi-arterial phase、view-sharingはsequence-specific。
再撮像の判定：動脈相のtimingと病変形態の両方が成立したか。

肝左葉に心拍動ghostが重なる

まず確認：ghostの走行方向を確認
動かす/確認するパラメータ操作の方向なぜ効くか代償・注意
Freq. Encode Direction phase方向を左葉から外す 心拍ghostの方向を移す wrap方向変化
Phase FOV / NPW 方向変更後のcoverageを再調整 wrapを防ぎつつ最短化 oversampling↑で時間増の可能性
NEX 必要時のみ ランダム成分平均化 時間↑
シーケンス固有の追加策：sequenceによってはcardiac motion suppression、SAT band等。
再撮像の判定：左葉病変周囲に周期的ghostが残っていないか。

3D MRCPが呼吸不規則で階段状・ぼやける

まず確認：呼吸波形/triggerの安定性を確認
動かす/確認するパラメータ操作の方向なぜ効くか代償・注意
FOV / Matrix 過剰分解能を見直す 1 respiratory window当たりの収集負担を軽減 細い胆管の分解能↓
NEX 過剰なら減らす 総時間短縮 SNR↓
Recon DL 対応ならSNR余裕を作る matrix/NEXを軽くしやすい 適用可否はsequence依存
Shim 脂肪抑制・off-resonanceが不安定なら再調整 背景抑制の安定化 呼吸motion自体は直さない
シーケンス固有の追加策：navigator window / respiratory acceptanceはsequence-specificで重要。
再撮像の判定：MIPだけでなくsource imageで偽狭窄を確認。

副腎/腎Dynamicのsubtractionが呼吸位相ずれで破綻

まず確認：Pre/Postを同じ呼気位で撮れているか
動かす/確認するパラメータ操作の方向なぜ効くか代償・注意
Scan time related parameters Phase matrix/NEX/Phase FOVを見直して短時間化 呼吸位相の再現性を上げる 分解能/SNR低下
FOV / slice prescription Pre/Postで固定 位置対応を担保 途中変更禁止
PURE / Prescan 受信濃淡が不自然なら確認 均一性を安定化 motion補正ではない
シーケンス固有の追加策：breath-hold coachingが最優先。
再撮像の判定：subtractionではなくsource imageで真の増強を確認。

7. 骨盤（婦人科・前立腺）

添付「部位別MRI」から課題を抽出

添付資料では、直腸ガスによるDWI歪み、腸管蠕動、臓器軸に沿う高分解能T2、DWI/T2/DCEの位置合わせが重要。

撮像開始前の基準：臓器軸に合わせたoblique断面と、T2/DWI/DCE間の位置整合を確認。

前立腺DWIが直腸ガスで強く歪む

まず確認：直腸ガス・患者準備を確認。その後B0対策。
動かす/確認するパラメータ操作の方向なぜ効くか代償・注意
Shim = Auto 前立腺中心のshimへ 局所off-resonanceを低減 ガスが多いと限界
Bandwidth 広げる EPI distortion↓ SNR↓
Freq. Encode Direction 歪み方向を前立腺の重要領域から逃がす artifact方向を変更 wrap方向変化
FOV / Phase FOV 小さすぎるphase FOVを見直す aliasingと歪みの重なりを軽減 分解能/時間tradeoff
シーケンス固有の追加策：parallel imaging、reduced-FOV DWIなどが使える場合あり。
再撮像の判定：高b値とADCの病変位置がT2と一致するか。

子宮頸部/前立腺T2を薄切・高matrixにしたらSNR不足

まず確認：Acq voxelとRelative SNRを確認
動かす/確認するパラメータ操作の方向なぜ効くか代償・注意
FOV 必要最小限にする 同matrixならpixel↓ さらにSNR↓
Matrix 過剰であれば少し戻す SNR改善 分解能↓
Slice Thickness 許容範囲で微増 voxel↑でSNR改善 z分解能↓
Bandwidth artifactに余裕があれば狭める SNR↑ chemical shift/distortion↑
Recon DL / NEX 最後に補償 高分解能維持 NEXは時間↑
シーケンス固有の追加策：「小FOV・薄切・高matrix」を同時に最大化しない。
再撮像の判定：被膜/筋層/parametriumなど診断対象の境界が見えるか。

腸管motion ghostが子宮/前立腺に重なる

まず確認：蠕動対策・鎮痙薬適応を確認
動かす/確認するパラメータ操作の方向なぜ効くか代償・注意
Freq. Encode Direction phase方向を病変から外す ghost方向変更 wrap方向変化
Phase FOV / NPW 新方向の身体幅に合わせる 時間/aliasing最適化 設定不足でwrap
ETL / Phase Matrix FSEなら短時間化を検討 motion中の収集時間短縮 ETL↑でblur、matrix↓で分解能↓
シーケンス固有の追加策：患者準備で改善できるmotionは、画質パラメータより先に対処。
再撮像の判定：artifactを『消す』より臓器から逃がせたか。

8. 四肢関節（肩・肘・手・股・膝・足）

添付「部位別MRI」から課題を抽出

添付資料では、小FOV・専用coil・解剖走行に合わせた断面、肩のmagic angle、人工関節金属が主要実務ポイント。

撮像開始前の基準：専用coil中心に関節を置き、身体軸ではなく腱・靱帯・関節面へ断面を合わせる。

手関節/肩で小FOV高matrixにしたらSNRが足りない

まず確認：coil中心・Acq voxel・Relative SNRを確認
動かす/確認するパラメータ操作の方向なぜ効くか代償・注意
Slice Thickness 少し厚くできるか検討 voxel↑でSNR↑ partial volume↑
Matrix 本当に必要な方向だけ高matrix 不要なSNR消費を削る 分解能↓
Bandwidth distortionに余裕があれば狭める SNR↑ chemical shift↑
Recon DL 高分解能を維持したままSNR補償 NEX/voxel変更を抑えられる 強度依存の見え方変化
NEX 最後の手段として増加 SNR↑ 時間↑
シーケンス固有の追加策：小関節はcoil choiceの影響が大きく、parameterより先にcoil placementを疑う。
再撮像の判定：SNRだけでなく腱・靱帯・TFCC等の描出を評価。

肩の脂肪抑制が不均一

まず確認：肩はB0不均一が起きやすい部位と認識
動かす/確認するパラメータ操作の方向なぜ効くか代償・注意
Shim = Auto 肩中心にshim B0均一性改善 解剖形状上の限界
Prescan Calibration coil位置変更後は再取得 frequency/RF調整 時間
Bandwidth 必要に応じ広げる off-resonance影響を抑える SNR↓
シーケンス固有の追加策：CHESSが不安定ならSTIR/Dixonへ変更。
再撮像の判定：腱板付着部周囲の脂肪抑制が均一か。

肩腱がmagic angleで高信号になり断裂と紛らわしい

まず確認：腱のB0に対する角度とTEを確認
動かす/確認するパラメータ操作の方向なぜ効くか代償・注意
TE 必要に応じ長めのT2-weighted像と比較 magic angle効果は短TEで目立ちやすい contrastが変わる
Scan Plane 腱走行に沿う断面へ partial volumeと角度依存性を評価しやすい 撮像追加
シーケンス固有の追加策：これは『コンソール補正で消すartifact』というより、物理を理解して別contrast/断面で確認する問題。
再撮像の判定：長TE像で信号が持続するか、形態的断裂があるか。

人工股関節/術後金属で周囲が見えない

まず確認：1.5T・専用metal reductionの適用可否を確認
動かす/確認するパラメータ操作の方向なぜ効くか代償・注意
Bandwidth 広げる 金属周囲の周波数ずれをpixel内に収める SNR↓
Slice Thickness 薄く through-plane dephasingを抑える SNR↓
FOV / Matrix 小voxel化 partial volume低減 SNR↓/時間↑
Recon DL 高BW・薄切のSNR補償 metal対策を成立させやすい 適用可否確認
シーケンス固有の追加策：SEMAC/MAVRIC等があれば使用を検討。
再撮像の判定：金属artifact縮小だけでなく臨床対象（腱、骨髄、神経）が見えるか。

9. 全身MRI

添付資料では、station間overlap、脂肪抑制ムラ、DWI歪み、ADCスケールの一貫性が重要。

stationごとに濃淡が大きく違う
